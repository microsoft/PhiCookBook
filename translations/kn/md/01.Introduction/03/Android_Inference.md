# **ಆಂಡ್ರಾಯ್ಡ್‌ನಲ್ಲಿ Inference Phi-3**

ಆಂಡ್ರಾಯ್ಡ್ ಸಾಧನಗಳ ಮೇಲೆ Phi-3-mini ಬಳಸಿ ಹೇಗೆ ಇನ್ಫರೆನ್ಸ್ ನಡೆಸಬಹುದು ಎಂಬುದನ್ನು ಅರಿತುಕೊಳ್ಳೋಣ. Phi-3-mini ಮೈಸ್ರೋಸಾಫ್ಟ್‌ನಿಂದ ಹೊಸ ಸರಣಿಯ ಮಾದರಿಗಳಾಗಿದ್ದು, ಎಡ್ಜ್ ಸಾಧನಗಳು ಮತ್ತು ಐಒಟಿ ಸಾಧನಗಳ ಮೇಲೆ ಲಾರ್ಜ್ ಲ್ಯಾಂಗ್ವೇಜ್ ಮಾದರಿಗಳನ್ನು (LLMs) ನಿಯೋಜಿಸಲು ಅನುಮತಿಸುತ್ತದೆ.

## ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್ ಮತ್ತು ಇನ್ಫರೆನ್ಸ್

[ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್](https://github.com/microsoft/semantic-kernel) ಎಂಬುದು ಆಜೂರ್ ಓಪನ್‌ಎಐ ಸೇವೆ, ಓಪನ್‌ಎಐ ಮಾದರಿಗಳು ಮತ್ತು ಸ್ಥಳೀಯ ಮಾದರಿಗಳೊಂದಿಗೆ ಹೊಂದಿಕೊಳ್ಳುವ ಅಪ್ಲಿಕೇಶನ್ ಫ್ರೇಮ್ವರ್ಕ್ ಆಗಿದೆ. ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್‌ ಬಗ್ಗೆ ಹೊಸದಾದರೆ, ನಾವು ನಿಮಗೆ [ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್ ಕುಕ್‌ಬುಕ್](https://github.com/microsoft/SemanticKernelCookBook?WT.mc_id=aiml-138114-kinfeylo) ಅನ್ನು ನೋಡಲು ಸಲಹೆ ನೀಡುತ್ತೇವೆ.

### ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್ ಮೂಲಕ Phi-3-mini ಗೆ ಪ್ರಾಪ್ತಿ ಹೊಂದುವುದು

ನೀವು ಇದನ್ನು ಸಿಮೆಂಟಿಕ್ ಕರ್‌ನೆಲ್‌ನ ಹಗ್ಗಿಂಗ್ ಫೇಸ್ ಕನೆಕ್ಟರ್‌ ಜೊತೆ ಸಂಯೋಜಿಸಬಹುದು. ಈ [ನದಿ ಕೋಡ್](https://github.com/Azure-Samples/Phi-3MiniSamples/tree/main/semantickernel?WT.mc_id=aiml-138114-kinfeylo) ಅನ್ನು ನೋಡಿ.

ಡೀಫಾಲ್ಟ್‌ನಂತೆ, ಇದು ಹಗ್ಗಿಂಗ್ ಫೇಸ್‌ನ ಮೈಡು ID ಗೆ ಹೊಂದಿಕೊಂಡಿದೆ. ಆದರೆ, ನೀವು ಸ್ಥಳೀಯವಾಗಿ ನಿರ್ಮಿಸಿದ Phi-3-mini ಮಾದರಿ ಸರ್ವರ್‌ಗೆ ಕೂಡ ಸಂಪರ್ಕಿಸಬಹುದು.

### Quantized ಮಾದರಿಗಳನ್ನು Ollama ಅಥವಾ LlamaEdge ಮೂಲಕ ಕರೆಮಾಡುವುದು

ಹಲವಾರು ಬಳಕೆದಾರರು ಸ್ಥಳೀಯವಾಗಿ ಮಾದರಿಗಳನ್ನು ಚಲಿಸಲು quantized ಮಾದರಿಗಳನ್ನು ಬಳಸುವುದನ್ನು ಇಷ್ಟಪಡುತ್ತಾರೆ. [Ollama](https://ollama.com/) ಮತ್ತು [LlamaEdge](https://llamaedge.com) ವಿವಿಧ quantized ಮಾದರಿಗಳನ್ನು ಕರೆಮಾಡಲು ವೈಯಕ್ತಿಕ ಬಳಕೆದಾರರಿಗೆ ಅವಕಾಶ ನೀಡುತ್ತವೆ:

#### Ollama

ನೀವು ನೇರವಾಗಿ `ollama run Phi-3` ಅನ್ನು ಓಡಿಸಬಹುದು ಅಥವಾ ನಿಮ್ಮ `.gguf` ಫೈಲ್‌ನ ಪಥದೊಂದಿಗೆ `Modelfile` ರಚಿಸಿ ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಓಡಿಸಬಹುದು.

```gguf
FROM {Add your gguf file path}
TEMPLATE \"\"\"<|user|> .Prompt<|end|> <|assistant|>\"\"\"
PARAMETER stop <|end|>
PARAMETER num_ctx 4096
```

[ನದಿ ಕೋಡ್](https://github.com/Azure-Samples/Phi-3MiniSamples/tree/main/ollama?WT.mc_id=aiml-138114-kinfeylo)

#### LlamaEdge

ನೀವು ಮೋಡ ಮತ್ತು ಎಡ್ಜ್ ಸಾಧನಗಳ ಎರಡಲ್ಲಾ `.gguf` ಫೈಲ್‌ಗಳನ್ನು ಬಳಸಲು ಬಯಸಿದರೆ, LlamaEdge ಒಂದು ಸೂಕ್ತ ಆಯ್ಕೆಯಾಗಿದೆ. ಪ್ರಾರಂಭಿಸಲು ಈ [ನದಿ ಕೋಡ್](https://github.com/Azure-Samples/Phi-3MiniSamples/tree/main/wasm?WT.mc_id=aiml-138114-kinfeylo) ಅನ್ನು ನೋಡಿ.

### ಆಂಡ್ರಾಯ್ಡ್ ಫೋನ್‌ಗಳಲ್ಲಿ ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ ಓಡಿಸುವುದು

1. **MLC Chat ಆಪ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ** (ಉಚಿತ) ಆಂಡ್ರಾಯ್ಡ್ ಫೋನ್‌ಗಳಿಗೆ.
2. APK ಫೈಲ್ (148MB) ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಇನ್ಸ್ಟಾಲ್ ಮಾಡಿ.
3. MLC Chat ಆಪ್ ಅನ್ನು ಆರಂಭಿಸಿ. Phi-3-mini ಸಹಿತ AI ಮಾದರಿಗಳ ಪಟ್ಟಿ ಕಾಣಿಸುತ್ತದೆ.

### LiteRT-LM ಮೂಲಕ Phi-4-mini-reasoning ಓಡಿಸುವುದು

[Phi-4-mini-reasoning](https://huggingface.co/litert-community/Phi-4-mini-reasoning) ಉತ್ತಮ ಸಮುದಾಯ ಕಂಡುಬಂದ int4 `.litertlm` ಘನಸಂಗ್ರಹವಾಗಿದೆ, ಇದು Google ನ [LiteRT-LM](https://github.com/google-ai-edge/LiteRT-LM) on-device ರನ್‌ಟೈಮ್‌ಗೆ ಇರುತ್ತದೆ. ಆಂಡ್ರಾಯ್ಡ್‌ನಲ್ಲಿ ಇದು CPU ಅಥವಾ GPU ಮೇಲೆ [Google AI Edge Gallery](https://github.com/google-ai-edge/gallery) ಆಪ್ ಮೂಲಕ (ಆಪ್ ಒಳಗೆ ಹಗ್ಗಿಂಗ್ ಫೇಸ್‌ನಿಂದ ಘನಸಂಗ್ರಹವನ್ನು ಆಮದು ಮಾಡಿ) ಅಥವಾ LiteRT-LM Kotlin API ಮೂಲಕ ಓಡುತ್ತದೆ; ಅದೇ ಘನಸಂಗ್ರಹವು iOS, macOS, Linux ಮತ್ತು Windows ಮೇಲೆಯೂ ಓಡುತ್ತದೆ. ಮಾದರಿ ಕಾರ್ಡ್ ನಿರ್ದಿಷ್ಟ ಗತಿಯನ್ನೂ ಮತ್ತು ರನ್ ಆದೇಶಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಿದೆ.

ಹೆಚ್ಚಾಗಿ ಹೇಳುವುದಾದರೆ, Phi-3-mini ಎಡ್ಜ್ ಸಾಧನಗಳ ಮೇಲೆ ಜನರೇಟಿವ್ AI ಗಾಗಿ ರೋಚಕ ಸಾಧ್ಯತೆಗಳನ್ನು ತೆರೆದಿದೆ ಮತ್ತು ನೀವು ಆಂಡ್ರಾಯ್ಡ್‌ನಲ್ಲಿ ಅದರ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಅನ್ವೇಷಿಸಲು ಪ್ರಾರಂಭಿಸಬಹುದು.
