## សន្តិសុខ

Microsoft យកចិត្តទុកដាក់យ៉ាងខ្លាំងចំពោះសន្តិសុខនៃផលិតផលកម្មវិធី និងសេវាកម្មរបស់យើង ដែលរួមបញ្ចូលទាំងឃ្លាំងកូដបណ្តាលក្រោមការគ្រប់គ្រងតាមរយៈអង្គការជា GitHub របស់យើង ដែលរួមមាន [Microsoft](https://github.com/Microsoft), [Azure](https://github.com/Azure), [DotNet](https://github.com/dotnet), [AspNet](https://github.com/aspnet) និង [Xamarin](https://github.com/xamarin)។

បើអ្នកជឿជាក់ថា អ្នកបានរកឃើញចំណុចខ្សោយសន្តិសុខនៅក្នុងឃ្លាំងទិន្នន័យណាមួយដែលកាន់ដោយ Microsoft ដែលសមរម្យទៅនឹង [និយមន័យរបស់ Microsoft ស្តីពីចំណុចខ្សោយសន្តិសុខ](https://aka.ms/security.md/definition) សូមរាយការណ៍មកយើងតាមការពិពណ៌នាខាងក្រោម។

## រាយការណ៍បញ្ហាសន្តិសុខ

**សូមកុំរាយការណ៍ចំណុចខ្សោយសន្តិសុខតាមរយៈបញ្ហាសាធារណៈលើ GitHub។**

ជំនួស វិញសូមរាយការណ៍ទៅកាន់មណ្ឌលប្រតិកម្មសន្តិសុខ Microsoft (MSRC) តាម [https://msrc.microsoft.com/create-report](https://aka.ms/security.md/msrc/create-report)។

បើអ្នកចង់ដាក់សំណើដោយមិនចូលប្រើប្រាស់ គឺអាចផ្ញើអ៊ីមែលទៅ [secure@microsoft.com](mailto:secure@microsoft.com)។ ប្រសិនបើអាចធ្វើទៅបាន សូមរៀបចំរូបសារ​របស់អ្នកជាមួយកូនសោ PGP របស់យើង។ សូមទាញយកវាពី [ទំព័រកូនសោ PGP មណ្ឌលប្រតិកម្មសន្តិសុខ Microsoft](https://aka.ms/security.md/msrc/pgp)។

អ្នកគួរតែលំអិតឆ្លើយតបក្នុងរយៈពេល 24 ម៉ោង។ បើមានហេតុផលណាមួយដែលមិនទទួលបាន សូមបន្តសួរតាមអ៊ីមែល ដើម្បីធានាថាយើងបានទទួលសារដើមរបស់អ្នក។ ព័ត៌មានបន្ថែមអាចរកបាននៅ [microsoft.com/msrc](https://www.microsoft.com/msrc)។

សូមរួមបញ្ចូលព័ត៌មានដែលបានស្នើសុំខាងក្រោម (បើអាចផ្តល់បាន) ដើម្បីជួយយើងយល់ដឹងពីប្រភេទ និងវិសាលភាពនៃបញ្ហាដែលអាចកើតមាន៖

  * ប្រភេទបញ្ហា (ឧ. ការលើកលម្អិតកម្មវិធីយូរពេក, SQL injection, cross-site scripting, ជាដើម)
  * ផ្លូវពេញលេញនៃឯកសារបញ្ជីកូដដែលពាក់ព័ន្ធនឹងបញ្ហា
  * ទីតាំងនៃកូដកំណត់ (tag/branch/commit ឬ URL ត្រង់)
  * ការបង្កើតរចនាសម្ព័ន្ធពិសេសណាមួយដែលត្រូវការ ដើម្បីផ្ទៀតផ្ទាត់បញ្ហា
  * ជំហាន​ដូចជាដើម ដើម្បីបានលទ្ធផលស្របតាមបញ្ហា
  * ពាក្យសម្គាល់-គំនិត ឬកូដប្រើប្រាស់ (បើអាចធ្វើទៅបាន)
  * ប្រសិទ្ធិភាពនៃបញ្ហា រួមទាំងវិធីដែលអ្នកវាយប្រហារ​អាចយកប្រយោជន៍ពីបញ្ហា

ព័ត៌មាននេះនឹងជួយយើងដំណើរការរាយការណ៍របស់អ្នកបានរហ័សជាងមុន។

បើអ្នកកំពុងរាយការណ៍សម្រាប់រង្វាន់កំហុស (bug bounty) របាយការណ៍ពេញលេញនឹងជួយឱ្យអ្នកទទួលបានរង្វាន់ខ្ពស់ជាងមុន។ សូមចូលទៅកាន់ទំព័រ [កម្មវិធីរង្វាន់កំហុស Microsoft](https://aka.ms/security.md/msrc/bounty) សម្រាប់ព័ត៌មានលម្អិតបន្ថែមអំពីកម្មវិធីសកម្មរបស់យើង។

## ភាសាជ្រើសរើស

យើងពិចារណានូវការប្រាស្រ័យទាក់ទងគ្រប់ប្រភេទជា ភាសាអង់គ្លេស។

## គោលការណ៍

Microsoft អនុវត្តតាមគោលការណ៍ [ការបង្ហាញចំណុចខ្សោយសន្តិសុខដែលបានសម្រឹម](https://aka.ms/security.md/cvd)។
