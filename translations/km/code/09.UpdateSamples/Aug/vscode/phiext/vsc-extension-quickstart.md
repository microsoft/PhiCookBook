# ស្វាគមន៍មកកាន់កម្មវិធីបន្ថែម VS Code របស់អ្នក

## អ្វីដែលមានក្នុងថត

* ថតនេះមានឯកសារទាំងអស់ដែលចាំបាច់សម្រាប់កម្មវិធីបន្ថែមរបស់អ្នក។
* `package.json` - នេះគឺជាឯកសារមេនហ្វេស្ទីដែលអ្នកប្រកាសពីកម្មវិធីបន្ថែម និងពាក្យបញ្ជារបស់អ្នក។
  * ប្លង់ឧទាហរណ៍នេះចុះបញ្ជីពាក្យបញ្ជា និងកំណត់ចំណងជើង និងឈ្មោះពាក្យបញ្ជា។ ជាមួយព័ត៌មាននេះ VS Code អាចបង្ហាញពាក្យបញ្ជា ក្នុង command palette ។ វានៅតែមិនត្រូវការ​ដើម្បី​ផ្ទុក​ប្លង់​ឡើង​ទេ។
* `src/extension.ts` - នេះគឺជា​ឯកសារចម្បងដែលអ្នកនឹងផ្តល់នូវការអនុវត្តន៍នៃពាក្យបញ្ជារបស់អ្នក។
  * ឯកសារនេះនាំចេញមុខងារមួយ `activate` ដែលត្រូវបានហៅជាលើកដំបូងនៅពេលកម្មវិធីបន្ថែមរបស់អ្នកត្រូវបានចាប់ផ្តើម (នៅករណីនេះដោយការបញ្ជា​ពាក្យបញ្ជា)។ ខាងក្នុងមុខងារ `activate` យើងហៅ `registerCommand`។
  * យើងផ្ញើមុខងារដែលមានការអនុវត្តន៍ពាក្យបញ្ជា ជាប៉ារ៉ាម៉ែត្រជាទីពីរទៅ `registerCommand`។

## ការតំឡើង

* តំឡើងកម្មវិធីបន្ថែមដែលបានណែនាំ (amodio.tsl-problem-matcher, ms-vscode.extension-test-runner, និង dbaeumer.vscode-eslint)


## ចាប់ផ្តើមប្រើប្រាស់ភ្លាមៗ

* ចុច `F5` ដើម្បីបើកបង្អួចថ្មីដែលបានផ្ទុកកម្មវិធីបន្ថែមរបស់អ្នក។
* រៀបចំពាក្យបញ្ជារបស់អ្នកពី command palette ដោយចុច (`Ctrl+Shift+P` ឬ `Cmd+Shift+P` លើ Mac) ហើយវាយពាក្យ `Hello World`។
* កំណត់ breakpoints ក្នុងកូដរបស់អ្នកនៅក្នុង `src/extension.ts` ដើម្បីបន្ទាបកំហុសកម្មវិធីបន្ថែម។
* រកមើលលទ្ធផល​ពី​កម្មវិធី​បន្ថែម​របស់​អ្នក​នៅ​ក្នុង​កុងសូល debug។

## ធ្វើការផ្លាស់ប្តូរ

* អ្នកអាចបញ្ចូលកម្មវិធីបន្ថែមឡើងវិញពី toolbar debug បន្ទាប់ពីផ្លាស់ប្តូរកូដក្នុង `src/extension.ts`។
* អ្នកអាចផ្ទុកឡើងវិញ (reload) (`Ctrl+R` ឬ `Cmd+R` លើ Mac) បង្អួច VS Code ជាមួយកម្មវិធីបន្ថែមរបស់អ្នក ដើម្បីផ្ទុកការផ្លាស់ប្តូររបស់អ្នក។

## ស្វែងយល់អំពី API

* អ្នកអាចបើកកំណត់ពេញលេញនៃ API របស់យើងនៅពេលអ្នកបើកឯកសារ `node_modules/@types/vscode/index.d.ts`។

## បើករត់ការប្រលង

* តំឡើង [Extension Test Runner](https://marketplace.visualstudio.com/items?itemName=ms-vscode.extension-test-runner)
* រត់ភារកិច្ច "watch" តាមរយៈពាក្យបញ្ជា **Tasks: Run Task** ។ ត្រូវប្រាកដថាភារកិច្ចនេះកំពុងរត់ អ sonst tests មិនគួរត្រូវបានរកឃើញ។
* បើកមើល Testing view ពី activity bar និងចុចប៊ូតុង Run Test" ឬប្រើក្តារចុច​ពិសេស `Ctrl/Cmd + ; A`
* មើលលទ្ធផលនៃតេស្តក្នុង Test Results view ។

* ធ្វើការផ្លាស់ប្តូរទៅ `src/test/extension.test.ts` ឬបង្កើតឯកសារតេស្តថ្មីៗនៅក្នុងថត `test` ។
  * test runner ដែលបានផ្តល់មកនឹងពិចារណា​រួចត្រឹមតែឯកសារដែលឈ្មោះត្រូវនឹងប្រភេទ `**.test.ts` ប៉ុណ្ណោះ។
  * អ្នកអាចបង្កើតថតនៅក្នុងថត `test` ដើម្បីរៀបចំតេស្តរបស់អ្នកទៅតាមរបៀបណាមួយដែលអ្នកចង់។

## ទៅឆ្ងាយជាងនេះ

* បន្សំទំហំកម្មវិធីបន្ថែម និងបង្កើនពេលចាប់ផ្តើមដោយ [ការចងកម្មវិធីបន្ថែមរបស់អ្នក](https://code.visualstudio.com/api/working-with-extensions/bundling-extension)។
* [ផ្សព្វផ្សាយកម្មវិធីបន្ថែមរបស់អ្នក](https://code.visualstudio.com/api/working-with-extensions/publishing-extension) នៅលើផ្សារកម្មវិធីបន្ថែម VS Code។
