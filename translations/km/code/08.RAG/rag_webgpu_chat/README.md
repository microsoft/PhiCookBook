## តើ WebGPU ជាអ្វី
WebGPU គឺជាអ្នកតំណាងរំលេចសម័យកែប្រើសំរាប់គេហទំព័រភាសាប្លុកក្រាហ្វិក ដែលមានគោលបំណងផ្តល់ការចូលដំណើរការប្រសើរចំពោះឧបករណ៍បង្ហាញក្រាហ្វិក (GPU) តាមរយៈកម្មវិធីរុករកគេហទំព័រ។ វាត្រូវបានរចនាឡើងជំនួសឲ្យ WebGL ដែលផ្តល់ការកែលម្អសំខាន់ៗ ដូចជា៖

1. **ភាពសមរម្យជាមួយ GPU សម័យថ្មី**: WebGPU ត្រូវបានកសាងឡើងសម្រាប់ដំណើរការជាមួយស្ថាបត្យកម្ម GPU សម័យទំនើប ដោយប្រើប្រាស់ API ប្រព័ន្ធដូចជា Vulkan, Metal និង Direct3D 12។
2. **ប្រសិទ្ធភាពកាន់តែល្អ**: វាពាំនាំឲ្យមានការគណនា GPU ទៅទូទៅ និងប្រតិបត្តិការលឿនជាង មួយដែលសមស្របសម្រាប់ការបង្ហាញក្រាហ្វិក និងបំពេញភារកិច្ចរៀនម៉ាស៊ីន។
3. **លក្ខណៈពិសេសជ្រៅជាង**: WebGPU ផ្តល់ការចូលដំណើរការបច្ចេកគ្រឿង GPU ប្រសើរជាងមុន អាចបង្កើតក្រាហ្វិក និងការប្រតិបត្តិការ​ដែលស្មុគស្មាញ និងឆ្លាតវៃ។
4. **ការបន្ថយការងារច្រើននៅ JavaScript**: ដោយភារកិច្ចមួយចំនួនត្រូវបានផ្ទេរទៅ GPU, WebGPU ធ្វើអោយការងាររបស់ JavaScript ខ្លាំងតិចធ្វើអោយមានប្រសិទ្ធភាពល្អ និងបទពិសោធន៍រលូន។

បច្ចុប្បន្ននេះ WebGPU ត្រូវបានគាំទ្រនៅក្នុងកម្មវិធីរុករកដូចជា Google Chrome ហើយកំពុងមានការងារដើម្បីពង្រីកសេវាកម្មលើវេទិកាផ្សេង។

### បើក WebGPU៖

#### បើកកម្មវិធីរុករករបស់អ្នក៖
ផ្តើម Google Chrome ឬ Microsoft Edge ។

#### ចូលទៅកាន់ទំព័រ Flags៖
នៅក្នុងរបារអាសយដ្ឋាន សរសេរ `chrome://flags` ហើយចុច Enter ។

#### ស្វែងរកបញ្ចាំង៖
នៅក្នុងប្រអប់ស្វែងរកនៅខាងលើ សរសេរ 'enable-unsafe-webgpu' ។

#### បើកបញ្ចាំង៖
ស្វែងរកបញ្ចាំង #enable-unsafe-webgpu ក្នុងបញ្ជីលទ្ធផល ។

ចុចម៉ឺនុយចុះខាងមុខវា និងជ្រើសរើស Enabled ។

#### ចាប់ផ្ដើមកម្មវិធីរុករករបស់អ្នកម្ដងទៀត៖

បន្ទាប់ពីបើកបញ្ចាំង អ្នកត្រូវចាប់ផ្ដើមកម្មវិធីរុករកឡើងវិញដើម្បីអនុវត្តការផ្លាស់ប្តូរ។ ចុចប៊ូតុង Relaunch ដែលបង្ហាញនៅខាងក្រោមទំព័រ។

- សម្រាប់ Linux, ផ្ដើមកម្មវិធីរុករកជាមួយ `--enable-features=Vulkan` ។
- Safari 18 (macOS 15) មានការបើក WebGPU ជាធម្មតា។
- ក្នុង Firefox Nightly, ចូល about:config នៅក្នុងរបារអាសយដ្ឋាន ហើយកំណត់ `dom.webgpu.enabled` ទៅ true ។

### ការតំឡើង GPU សម្រាប់ Microsoft Edge
