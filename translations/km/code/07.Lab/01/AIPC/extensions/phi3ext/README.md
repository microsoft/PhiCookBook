# phi3ext README

## Features

ពិពណ៌នាអំពីមុខងារពិសេសនៃបន្ថែមរបស់អ្នក រួមមានរូបថតអេក្រង់ក្នុងអំឡុងពេលបន្ថែមដំណើរការ។ ផ្លូវរូបភាពគឺអាស្រ័យលើឯកសារ README នេះ។

## Requirements

បើអ្នកមានតម្រូវការឬការពឹងផ្អែកណាមួយ សូមបន្ថែមថ្នាក់មួយពិពណ៌នាអំពីតម្រូវការនិងរបៀបដំឡើង និងកំណត់តម្លៃ។

## Extension Settings

បើបន្ថែមរបស់អ្នកបានបន្ថែមកំណត់តម្លៃណាមួយទៅ VS Code តាមរយៈ `contributes.configuration` សូមរួមបញ្ចូលវា។

ឧទាហរណ៍៖

បន្ថែមនេះបានចូលរួមនូវការកំណត់ខាងក្រោម៖

* `myExtension.enable`: បើក/បិទបន្ថែមនេះ។
* `myExtension.thing`: កំណត់ជា `blah` ដើម្បីធ្វើករណីមួយ។

## Following extension guidelines

ធានាថាអ្នកទើបបានអានមគ្គុទេសក៍បន្ថែមហើយអនុវត្តតាមអនុប្រតិបត្តិល្អបំផុតសម្រាប់ការបង្កើតបន្ថែម។

* [មគ្គុទេសក៍បន្ថែម](https://code.visualstudio.com/api/references/extension-guidelines?WT.mc_id=aiml-137032-kinfeylo)

## Working with Markdown

អ្នកអាចប្រើ Visual Studio Code ដើម្បីសរសេរ README របស់អ្នក។ នេះជាបញ្ជីបញ្ចូលក្តារចុចរហ័សសម្រាប់កែសម្រួល៖

* បំបែកកែសម្រួល (`Cmd+\` លើ macOS ឬ `Ctrl+\` លើ Windows និង Linux)។
* ប្ដូរមើល 미តមួយ (`Shift+Cmd+V` លើ macOS ឬ `Shift+Ctrl+V` លើ Windows និង Linux)។
* ចុច `Ctrl+Space` (Windows, Linux, macOS) ដើម្បីមើលបញ្ជីកូដ Markdown។
