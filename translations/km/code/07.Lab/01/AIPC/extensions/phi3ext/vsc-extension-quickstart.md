# ស្វាគមន៍មកកាន់ការពង្រីក VS Code របស់អ្នក

## មានអ្វីក្នុងថតនេះ

* ថតនេះមានឯកសារទាំងអស់ដែលចាំបាច់សម្រាប់ការពង្រីករបស់អ្នក។
* `package.json` - នេះគឺជាឯកសារមេនហ្វេស្តដែលអ្នកប្រកាសការពង្រីក និង ពាក្យបញ្ជារបស់អ្នក។
  * គំរូផ្លាហ្គីនបានចុះបញ្ជីពាក្យបញ្ជា ហើយកំណត់ចំណងជើង និងឈ្មោះពាក្យបញ្ជា។ ជាមួយព័ត៌មាននេះ VS Code អាចបង្ហាញពាក្យបញ្ជានៅក្នុងប៉ាឡេតពាក្យបញ្ជា។ វាមិនចាំបាច់បញ្ចូលផ្លីហ្គីននៅឡើយទេ។
* `src/extension.ts` - នេះជាឯកសារសំខាន់ដែលអ្នកនឹងផ្តល់ការអនុវត្តន៍នៃពាក្យបញ្ជារបស់អ្នក។
  * ឯកសារនេះប​រ​ពេញមុខងារ​មួយគឺ `activate` ដែលត្រូវបានហៅលើកដំបូងពេលដែលការពង្រីករបស់អ្នកត្រូវបានបើក (ក្នុងករណីនេះដោយគណនាពាក្យបញ្ជា)។ នៅក្នុងមុខងារ `activate` យើងហៅ `registerCommand`។
  * យើងផ្ញើមុខងារដែលមានការអនុវត្តន៍ពាក្យបញ្ជាជាអប៉ារ៉ាម៉ែត្រទីពីរ ទៅកាន់ `registerCommand`។

## ការដំឡើង

* តំឡើងការពង្រីកដែលបានផ្តល់អនុសាសន៍ (amodio.tsl-problem-matcher, ms-vscode.extension-test-runner, និង dbaeumer.vscode-eslint)


## ចាប់ផ្តើមដំណើរការបន្ទាន់

* ចុច `F5` ដើម្បីបើកបង្អួចថ្មីដោយមានការពង្រីករបស់អ្នកបានផ្ទុក។
* ប្រតិបត្តិការពាក្យបញ្ជារបស់អ្នកពីប៉ាឡេតពាក្យបញ្ជា ដោយចុច (`Ctrl+Shift+P` ឬ `Cmd+Shift+P` លើ Mac) ហើយវាយ `Hello World`។
* កំណត់ចំណុចបំបែកនៅក្នុងកូដរបស់អ្នកក្នុងឯកសារ `src/extension.ts` ដើម្បីត្រួតពិនិត្យកំហុសការពង្រីករបស់អ្នក។
* រកមើលលទ្ធផលចេញពីការពង្រីករបស់អ្នកនៅក្នុងផ្ទាំង debug console។

## ប្រែប្រែ

* អ្នកអាចចាប់ផ្តើមការពង្រីកឡើងវិញពីរបប debug បន្ទាប់ពីបានផ្លាស់ប្ដូរកូដនៅក្នុង `src/extension.ts`។
* អ្នកក៏អាចផ្ទុកឡើងវិញ (ដោយចុច `Ctrl+R` ឬ `Cmd+R` នៅលើ Mac) តំណភ្ជាប់ VS Code ដែលមានការពង្រីករបស់អ្នក ដើម្បីផ្ទុកការផ្លាស់ប្ដូររបស់អ្នក។


## ស្វែងរក API

* អ្នកអាចបើកសំណុំនៃ API ពេញលេញរបស់យើងដោយបើកឯកសារ `node_modules/@types/vscode/index.d.ts`។

## ប្រតិបត្តិការពិសោធន៍

* តំឡើង [Extension Test Runner](https://marketplace.visualstudio.com/items?itemName=ms-vscode.extension-test-runner)
* បើកការងារ "watch" តាមរយៈពាក្យបញ្ជា **Tasks: Run Task**។ ត្រូវប្រាកដថាការបើកនេះកំពុងដំណើរការ មិនដូច្នោះទេសំណួ្រត្រូវត្រូវបានរកមិនឃើញ។
* បើកទិដ្ឋភាព Testing ពីរបារដំណើរការ ហើយចុចប៊ូតុង "Run Test" ឬប្រើក្តារចុចដែលមានដូចជា `Ctrl/Cmd + ; A`
* មើលលទ្ធផលនៃការធ្វើតេស្តនៅក្នុងទិដ្ឋភាព Test Results។
* ប្រែប្រួលឯកសារ `src/test/extension.test.ts` ឬបង្កើតឯកសារតេស្តថ្មីនៅក្នុងថត `test`។
  * ប្រតិបត្តិការកម្មវិធីតេស្តមានអ្វីដែលគិតគូទេតែឯកសារដែលផ្គូរផ្គងនិងលំនាំឈ្មោះ `**.test.ts`។
  * អ្នកអាចបង្កើតថតនៅក្នុងថត `test` ដើម្បីរៀបចំតេស្តរបស់អ្នកបានតាមរបៀបណាមួយដែលអ្នកចង់បាន។
