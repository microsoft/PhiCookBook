## Working with Markdown

អ្នកអាចប្រើ Visual Studio Code ដើម្បីសរសេរ README របស់អ្នក។ នៅទីនេះមានក្តារចុចលឿនដែលមានប្រយោជន៍៖

* បំបែកក្រុមអ្នកកែសម្រួល (`Cmd+\` នៅលើ macOS ឬ `Ctrl+\` នៅលើ Windows និង Linux)។
* ប្ដូរមើលមុន (`Shift+Cmd+V` នៅលើ macOS ឬ `Shift+Ctrl+V` នៅលើ Windows និង Linux)។
* ចុច `Ctrl+Space` (Windows, Linux, macOS) ដើម្បីមើលបញ្ជីស្នាដៃ Markdown ។
