# សូមស្វាគមន៍មកកាន់ផ្នែកពង្រីក VS Code របស់អ្នក

## មានអ្វីនៅក្នុងថត

* ថតនេះមានឯកសារទាំងអស់ដែលចាំបាច់សម្រាប់ផ្នែកពង្រីករបស់អ្នក។
* `package.json` - នេះគឺជាឯកសារមានផ្ទាំងក្នុងដែលអ្នកប្រកាសផ្នែកពង្រីក និងពាក្យបញ្ជារបស់អ្នក។
  * ផ្នែកពង្រីកផ្នែកគំរូបានចុះបញ្ជីពាក្យបញ្ជា និងកំណត់ចំណងជើង និងឈ្មោះពាក្យបញ្ជារ។ ជាមួយព័ត៌មាននេះ VS Code អាចបង្ហាញពាក្យបញ្ជានៅក្នុងបន្ទះពាក្យបញ្ជា។ វានៅមិនចាំបាច់ផ្ទុកផ្ល್ಗអុុននៅពេលនេះទេ។
* `src/extension.ts` - នេះគឺជាឯកសារសំខាន់ដែលអ្នកនឹងផ្តល់ការអនុវត្តន៍នៃពាក្យបញ្ជារបស់អ្នក។
  * ឯកសារនេះនាំចេញមុខងារមួយឈ្មោះ `activate` ដែលត្រូវបានហៅជាលើកដំបូងពេលផ្នែកពង្រីករបស់អ្នកត្រូវបានសកម្ម (ក្នុងករណីនេះដោយអនុវត្តពាក្យបញ្ជា)។ ខាងក្នុងមុខងារ `activate` យើងហៅ `registerCommand`។
  * យើងបញ្ជូនមុខងារដែលមានការអនុវត្តន៍ពាក្យបញ្ជាឲ្យជា៉parameters ទីពីរទៅ `registerCommand`។

## ដំឡើង

* ដំឡើងផ្នែកពង្រីកដែលបានផ្ដល់អនុសាសន៍ (amodio.tsl-problem-matcher, ms-vscode.extension-test-runner, និង dbaeumer.vscode-eslint)


## ចាប់ផ្តើមរត់ភ្លាមៗ

* ចុច `F5` ដើម្បីបើកវីនដោថ្មីជាមួយផ្នែកពង្រីករបស់អ្នកបានផ្ទុក។
* រត់ពាក្យបញ្ជារបស់អ្នកពីបន្ទះពាក្យបញ្ជា ដោយចុចបង្អួច (`Ctrl+Shift+P` ឬ `Cmd+Shift+P` លើ Mac) ហើយវាយ `Hello World`។
* កំណត់ចំណុចបំបែកកូដនៅក្នុង `src/extension.ts` ដើម្បីដាក់ច្រកដំណើរការបញ្ហា (debug) ផ្នែកពង្រីករបស់អ្នក។
* រកមើលលទ្ធផលចេញពីផ្នែកពង្រីករបស់អ្នកនៅក្នុងទិន្នន័យ debug console។

## ប្រែប្រាស់

* អ្នកអាចចាប់ផ្តើមផ្នែកពង្រីកឡើងវិញពីបន្ទះឧបករណ៍debug បន្ទាប់ពីកែប្រែកូដក្នុង `src/extension.ts`។
* អ្នកអាចផ្ទុកឡើងវិញវិញ (`Ctrl+R` ឬ `Cmd+R` លើ Mac) វីនដោ VS Code ជាមួយផ្នែកពង្រីករបស់អ្នក ដើម្បីផ្ទុកការផ្លាស់ប្តូររបស់អ្នក។


## ស្វែងយល់អំពី API

* អ្នកអាចបើកកំណត់ API ពេញលេញរបស់យើងពេលដែលអ្នកបើកឯកសារ `node_modules/@types/vscode/index.d.ts`។

## រត់តេស្ត

* ដំឡើង [Extension Test Runner](https://marketplace.visualstudio.com/items?itemName=ms-vscode.extension-test-runner)
* រត់បញ្ជាការតំណើរការ "watch" តាមរយៈពាក្យបញ្ជា **Tasks: Run Task**។ សូមប្រាកដថាប្រតិបត្តិនេះកំពុងរត់ ហើយមិនដូច្នោះតេស្តអាចមិនត្រូវបានរកឃើញទេ។
* បើកទស្សនាវិចិត្រតេស្តពីបន្ទះសកម្មភាព ហើយចុចប៊ូតុង "Run Test" ឬប្រើក្តារចុចខ្លី `Ctrl/Cmd + ; A`
* មើលលទ្ធផលតេស្តនៅក្នុងទស្សនាវិចិត្រក្នុង Test Results។
* បង្កើតការផ្លាស់ប្តូរនៅ `src/test/extension.test.ts` ឬបង្កើតឯកសារតេស្តថ្មីនៅក្នុងថត `test`។
  * មុខងារតេស្តដែលផ្តល់នឹងពិនិត្យលើឯកសារដែលផ្គូរផ្គងនឹងប្រភេទឈ្មោះ `**.test.ts`។
  * អ្នកអាចបង្កើតថតនៅក្នុងថត `test` ដើម្បីរៀបចំតេស្តរបស់អ្នកបានតាមចំណង់ចំណូលចិត្ត។

## ទៅមុខទៀត

* បង្រួមទំហំផ្នែកពង្រីក និងឆាប់ចាប់ផ្តើមវីនដោដោយ [bundling your extension](https://code.visualstudio.com/api/working-with-extensions/bundling-extension)។
* [ផ្សព្វផ្សាយផ្នែកពង្រីករបស់អ្នក](https://code.visualstudio.com/api/working-with-extensions/publishing-extension) នៅលើផ្សារផ្នែកពង្រីក VS Code។
* ស្វ័យប្រវត្តិកម្មការបញ្ចេញដោយកំណត់ [Continuous Integration](https://code.visualstudio.com/api/working-with-extensions/continuous-integration)។
