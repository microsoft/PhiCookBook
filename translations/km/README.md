Phi គឺជាស៊េរីនៃម៉ូដែល AI ប្រភពបើកដែលបានកែលម្អដោយ Microsoft។

Phi ជាឥឡូវនេះគឺជាម៉ូដែលភាសាតូច (SLM) ដែលមានថាមពលខ្ពស់បំផុត និងមានតម្លៃប្រកួតប្រជែងបានល្អជាមួយសន្ទស្សន៍ល្អក្នុងភាសាច្រើន ការគិត ធ្វើអត្ថបទ/ជជែក កូដ បទបង្ហាញរូបភាព សំឡេង និងឱកាសផ្សេងទៀត។

អ្នកអាចដាក់អនុវត្ត Phi ទៅក្នុងមេឃ ឬឧបករណ៍តែមួយ ហើយអាចបង្កើតកម្មវិធីបង្កើត AI បានយ៉ាងងាយស្រួលជាមួយថាមពលគណនានិងមានកំណត់។

> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git

> ```
>

## ការទទួលខុសត្រូវ AI

Microsoft បានខិតខំជួយអតិថិជនរបស់យើងប្រើផលិតផល AI របស់យើងដោយមានការទទួលខុសត្រូវ ចែករំលែកចំណេះដឹង និងបង្កើតកិច្ចសហប្រតិបត្តិការដែលមានមូលដ្ឋានលើទំនុកចិត្ត តាមរយៈឧបករណ៍ដូចជា Transparency Notes និង Impact Assessments។ ប្រភពធនធានជាច្រើនអាចរកឃើញនៅ [https://aka.ms/RAI](https://aka.ms/RAI).
វិធានការរបស់ Microsoft សម្រាប់ AI ទទួលខុសត្រូវមានមូលដ្ឋានលើគោលការណ៍ AI របស់យើង ដែលរួមមានភាពស្មើភាគភាព លំនាំល្អប្រសើរ មានសុវត្ថិភាព ជាប្រជាសម្បទា ការបង្ហាញច្បាស់លាស់ និងការទទួលខុសត្រូវ។

ម៉ូដែលភាសាជាធំ អក្សរូបភាព និងសំឡេង - ដូចជាម៉ូដែលដែលបានប្រើនៅក្នុងគំរូនេះ - អាចមានអាកប្បកម្មដែលមិនល្មម មិនគួរឱ្យទុកចិត្ត ឬបង្កការរអាក់រអល់ ដែលអាចបង្កហានិភ័យ។ សូមពិនិត្យមើល [Azure OpenAI service Transparency note](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) ដើម្បីទទួលបានព័ត៌មានពីហានិភ័យ និងកំណត់ដែនកំណត់។

វិធីសាស្ត្រដែលបានផ្តល់អនុសាសន៍សម្រាប់ការកាត់បន្ថយហានិភ័យទាំងនេះគឺការរួមបញ្ចូលប្រព័ន្ធសុវត្ថិភាពនៅក្នុងស្ថាបត្យកម្មរបស់អ្នកដែលអាចស្គាល់និងទប់ស្កាត់ចម្លើយអាក្រក់បាន។ [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) ផ្តល់ជាស្រទាប់ការពារឯករាជ្យ ដែលអាចស្គាល់មាតិកាដែលមានគ្រោះថ្នាក់ដែលបានបង្កើតដោយអ្នកប្រើនិង AI នៅក្នុងកម្មវិធីនិងសេវាកម្ម។ Azure AI Content Safety រួមមាន API អក្សរ និងរូបភាពដែលអនុញ្ញាតឲ្យអ្នកស្គាល់វត្ថុដែលគ្រោះថ្នាក់។ នៅក្នុង Microsoft Foundry សេវាកម្ម Content Safety អនុញ្ញាតឲ្យអ្នកមើល ស្វែងយល់ និងសាកល្បងកូដគំរូសម្រាប់ស្គាល់មាតិកាដែលគ្រោះថ្នាក់នៅលើច្រើនប្រភេទ។ ឯកសារ [quickstart documentation](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) ខាងក្រោមនេះនាំអ្នកឆ្ពោះទៅកាន់ការធ្វើសំណើទៅសេវាកម្ម។

មួយឯកតានៃចំណុចដែលត្រូវផ្តល់ចំណាំគឺសមត្ថភាពសរុបនៃកម្មវិធី។ ជាមួយកម្មវិធីពហុមុខងារនិងពហុគំរូ យើងពិចារណាសមត្ថភាពមានន័យថាប្រព័ន្ធដំណើរការដូចដែលអ្នកនិងអ្នកប្រើរបស់អ្នករំពឹងទុក រួមបញ្ចូលការមិនបង្កើតចម្លើយដែលគ្រោះថ្នាក់។ វាសំខាន់ក្នុងការវាស់វែងសមត្ថភាពរបស់កម្មវិធីសរុបរបស់អ្នក ដោយប្រើ [Performance and Quality and Risk and Safety evaluators](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in)។ អ្នកក៏អាចបង្កើតនិងវាស់វែងជាមួយ [custom evaluators](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators) បានផងដែរ។

អ្នកអាចវាស់វែងកម្មវិធី AI របស់អ្នកនៅក្នុងបរិយាកាសអភិវឌ្ឍន៍ដោយប្រើ [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html)។ ដោយផ្តល់ពីដាតាសែតសាកល្បង ឬ គោលដៅ ការបង្កើតរបស់កម្មវិធី AI របស់អ្នកត្រូវបានវាស់វែងដោយលេខគណនាបរិមាណជាមួយ evaluator ដែលមានរួចហើយ ឬ evaluator កំណត់ផ្ទាល់ខ្លួនដែលអ្នកជ្រើសរើស។ ដើម្បីចាប់ផ្តើមជាមួយ azure ai evaluation sdk សម្រាប់វាស់វែងប្រព័ន្ធរបស់អ្នក អ្នកអាចអនុវត្តតាម [quickstart guide](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk)។ ក្រោយពេលអនុវត្តន៍កាលវិភាគវាស់វែង អ្នកអាច [មើលលទ្ធផលនៅក្នុង Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results)។
