# សេចក្ដីសង្ខេបគម្រោង Phi-3-Vision-128K-Instruct

## ម៉ូឌែល

Phi-3-Vision-128K-Instruct គឺជាម៉ូឌែលពហុមូលដ្ឋានដែលមានទំហំទន់ភ្លន់ និងកម្រិតខ្ពស់ ដើមគេនៃគម្រោងនេះ។ វាជាផ្នែកមួយនៃគ្រួសារម៉ូឌែល Phi-3 ហើយគាំទ្ររយៈពេលបរិបទដល់ ១២៨,០០០ សញ្ញា។ ម៉ូឌែលនេះបានបង្រៀនលើឧទាហរណ៍ទិន្នន័យចម្រុះ ដែលរួមមានទិន្នន័យសម្រួល និងគេហទំព័រចុះបញ្ជីសាធារណៈដែលបានចម្រោះយ៉ាងសង្ឃឹម ប្រើកម្មវិធីដែលមានគុណភាពខ្ពស់ និងផ្អែកលើការគិតវិចារណញ្ញាណខ្ពស់។ ដំណើរការបង្រៀនរួមមានការបង្រៀនលម្អិតដោយគ្រប់គ្រង និងការបង្រៀនផ្ទាល់តាមចំណាប់អារម្មណ៍ ដើម្បីធានាការអនុវត្តតាមការណែនាំបានយ៉ាងត្រឹមត្រូវ និងមានវិធានការពារ សុវត្ថិភាពរឹងមាំផងដែរ។

## ការបង្កើតទិន្នន័យគំរូមានសារៈសំខាន់ក្នុងហេតុផលច្រើន៖

1. **ការធ្វើតេស្ត**៖ ទិន្នន័យគំរូអនុញ្ញាតឱ្យអ្នកធ្វើតេស្តកម្មវិធីរបស់អ្នកក្រោមស្ថានភាពនានា ដោយមិនប៉ះពាល់ទៅលើទិន្នន័យពិត។ វាសំខាន់ណាស់សម្រាប់ដំណាក់កាលអភិវឌ្ឍន៍ និងដំណាក់កាលជាស្តេចតែ។

2. **កំណត់ប្រសិទ្ធិភាព**៖ ជាមួយទិន្នន័យគំរូដែលច្បាស់លាស់ដូចទំហំ និងមេរៀនរបស់ទិន្នន័យពិត អ្នកអាចកំណត់ចំណុចដំណើរការអតិបរមា និងបង្កើតប្រសិទ្ធិភាពកម្មវិធីរបស់អ្នកតាមវា។

3. **ការបង្ហាញគំនិតអភិវឌ្ឍន៍**៖ ទិន្នន័យគំរូអាចប្រើក្នុងការបង្កើតគំរូខ្លះៗ និងគំរូស៊ាំ ដែលជួយក្នុងការយល់ដឹងអំពីតម្រូវការរបស់អ្នកប្រើ និងទទួលបានមតិយោបល់។

4. **វិភាគទិន្នន័យ**៖ នៅក្នុងវិទ្យាសាស្រ្តទិន្នន័យ ទិន្នន័យគំរូត្រូវបានប្រើសម្រាប់ការវិភាគទិន្នន័យ ចំណាត់ថ្នាក់ម៉ូឌែល និងការធ្វើតេស្តអាល់ហ្គូរិទ្ធម។

5. **សុវត្ថិភាព**៖ ការប្រើទិន្នន័យគំរូនៅក្នុងបរិយាកាសអភិវឌ្ឍន៍ និងធ្វើតេស្តអាចជួយទប់ស្កាត់ការលេចធ្លាយទិន្នន័យពិតដែលមានភាពរឹងប៉ឹង។

6. **ការរៀន**៖ ប្រសិនបើអ្នករៀនបច្ចេកវិទ្យាថ្មី ឧបករណ៍ថ្មី ការប្រើទិន្នន័យគំរូអាចផ្តល់នូវវិធីប្រាក់ប្រតិបត្តិពិសេសឱ្យអ្នកអនុវត្ត់អ្វីដែលបានរៀន។

ចងចាំថា គុណភាពទិន្នន័យគំរូរបស់អ្នកអាចមានឥទ្ធិពលយ៉ាងខ្លាំងលើសកម្មភាពទាំងនេះ។ វាចាំបាច់ត្រូវមានភាពស្រដៀងជិតស្និទ្ធជាមួយទិន្នន័យពិតក្នុងរចនាសម្ព័ន្ធ និងភាពខុសគ្នា។

## សំណុំទិន្នន័យ

ឧទាហរណ៍ល្អមួយនៃសំណុំទិន្នន័យគំរូគឺ [DBQ/Burberry.Product.prices.United.States dataset](https://huggingface.co/datasets/DBQ/Burberry.Product.prices.United.States) (មាននៅលើ Huggingface)។  
សំណុំទិន្នន័យគំរូនៃផលិតផល Burberry រួមជាមួយមេតាដាតាអំពីប្រភេទផលិតផល តម្លៃ និងចំណងជើង មានជួរដេរ ៣,០៤០ ខ្នាត ដែលនិរូបភាពកំពុងតំណាងផលិតផលដាច់ដោយឡែកមួយៗ។ សំណុំទិន្នន័យនេះអនុញ្ញាតឱ្យយើងធ្វើតេស្តសមត្ថភាពម៉ូឌែលក្នុងការយល់ពី និងបកស្រាយទិន្នន័យវិចិត្រសិល្បៈ រួមបង្កើតអត្ថបទពិពណ៌នាដែលពណ៌នាលម្អិតនិងលក្ខណៈពិសេសរបស់ម៉ាក។

**ចំណាំ៖** អ្នកអាចប្រើសំណុំទិន្នន័យណាមួយដែលមានរូបភាពជាមួយ។

## ការគិតស្មើតមួយដំណាក់កាលពិបាក

ម៉ូឌែលត្រូវការគិតអំពីតម្លៃ និងឈ្មោះ ដោយផ្អែកតែពីរូបភាពតែប៉ុណ្ណោះ។ វាតម្រូវឱ្យម៉ូឌែលមិនត្រឹមតែទទួលស្គាល់លក្ខណៈវិចិត្រសិល្បៈប៉ុណ្ណោះទេ តែត្រូវយល់ដឹងពីន័យនៃវាក្នុងទំនាក់ទំនងនឹងតម្លៃផលិតផល និងម៉ាក។ ដោយបង្កើតការពិពណ៌នាអត្ថបទឱ្យត្រឹមត្រូវពីរូបភាព គម្រោងនេះបង្ហាញពីសក្តានុពលនៃការរួមបញ្ចូលទិន្នន័យវិចិត្រសិល្បៈដើម្បីលើកកម្ពស់ប្រសិទ្ធិភាពនិងភាពច្រើនបែបរបស់ម៉ូឌែលនៅក្នុងកម្មវិធីពិភពលោកពិត។

## រចនាសម្ព័ន្ធ Phi-3 Vision

រចនាសម្ព័ន្ធម៉ូឌែលគឺជាកំណែពហុមូលដ្ឋាននៃ Phi-3។ វាបំលែងទាំងអត្ថបទ និងទិន្នន័យរូបភាព ដើម្បីបញ្ចូលចូលជាស៊េរីមួយសម្រាប់ការយល់ដឹង និងបង្កើតពហុមុខងារ។ ម៉ូឌែលប្រើស្រទាប់ embedding ផ្សេងគ្នាសម្រាប់អត្ថបទ និងរូបភាព។ សញ្ញាអត្ថបទត្រូវបានបម្លែងជាថង់វាងដង់ស៊ី ខណៈដែលរូបភាពត្រូវបានដំណើរកម្មតាមម៉ូឌែល CLIP vision ដើម្បីដកយក embedding លក្ខណៈពិសេស។ embedding រូបភាពទាំងនេះបន្ទាប់មកត្រូវបានបញ្ចាំងឡើងវិញឱ្យសមស្របជាមួយទំហំ embedding អត្ថបទ ដើម្បីធានាថាវាអាចបញ្ចូលគ្នាបានយ៉ាងរលូន។

## ការរួមបញ្ចូល embedding អត្ថបទ និងរូបភាព

សញ្ញាពិសេសនៅក្នុងស៊េរីអត្ថបទបង្ហាញកន្លែងដែល embedding រូបភាពត្រូវដាក់បញ្ចូល។ ក្នុងដំណើរការផ្ទៀងផ្ទាត់ សញ្ញាពិសេសទាំងនេះត្រូវបានជំនួសជាមួយ embedding រូបភាព ដែលអនុញ្ញាតឱ្យម៉ូឌែលដោះស្រាយអត្ថបទ និងរូបភាពជាស៊េរីតែមួយ។ ប្រអប់ prompt សម្រាប់សំណុំទិន្នន័យរបស់យើងត្រូវបានបំលែងដោយប្រើសញ្ញាពិសេស <|image|> ដូចតទៅ៖

```python
text = f"<|user|>\n<|image_1|>What is shown in this image?<|end|><|assistant|>\nProduct: {row['title']}, Category: {row['category3_code']}, Full Price: {row['full_price']}<|end|>"
```
