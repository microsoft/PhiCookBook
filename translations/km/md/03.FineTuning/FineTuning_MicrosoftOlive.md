### ការតំឡើង Microsoft Olive

ការតំឡើង Microsoft Olive ងាយស្រួលខ្លាំង និងអាចតំឡើងសម្រាប់ CPU, GPU, DirectML, និង Azure ML

```bash
pip install olive-ai
```
