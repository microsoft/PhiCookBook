# **មន្ទិល 0 - ការដំឡើង**

ពេលយើងចូលទៅក្នុងមន្ទិលនេះ យើងត្រូវតែបញ្ជាក់បរិបទដែលពាក់ព័ន្ធ៖


### **1. Python 3.11+**

បានណែនាំឱ្យប្រើ miniforge ដើម្បីកំណត់បរិបទ Python របស់អ្នក

ដើម្បីកំណត់ miniforge សូមយោងទៅកាន់ [https://github.com/conda-forge/miniforge](https://github.com/conda-forge/miniforge)

បន្ទាប់ពីកំណត់ miniforge ត្រូវរត់ពាក្យបញ្ជាខាងក្រោមនៅក្នុង Power Shell

```bash

conda create -n pyenv python==3.11.8 -y

conda activate pyenv

```


### **2. ដំឡើង Prompt flow SDK**

នៅក្នុងមន្ទិល 1 យើងប្រើ Prompt flow ដូច្នេះអ្នកត្រូវតែកំណត់ Prompt flow SDK។

```bash

pip install promptflow --upgrade

```

អ្នកអាចពិនិត្យ promptflow sdk នៅក្នុងពាក្យបញ្ជានេះ


```bash

pf --version

```

### **4. បណ្ណាល័យបង្កើនល្បឿន Intel NPU**

Processor ជំនាន់ថ្មីរបស់ Intel គាំទ្រ NPU។ ប្រសិនបើអ្នកចង់ប្រើ NPU ដើម្បីរត់ LLMs / SLMs ក្នុងស្ថានភាពក្នុងស្រុក អ្នកអាចប្រើ ***បណ្ណាល័យបង្កើនល្បឿន Intel NPU***។ ប្រសិនបើអ្នកចង់ដឹងបន្ថែម អ្នកអាចអាន [https://github.com/microsoft/PhiCookBook/blob/main/md/01.Introduction/03/AIPC_Inference.md](https://github.com/microsoft/PhiCookBook/blob/main/md/01.Introduction/03/AIPC_Inference.md)។

ដំឡើងបណ្ណាល័យបង្កើនល្បឿន Intel NPU ក្នុង bash


```bash

pip install intel-npu-acceleration-library

```

***កំណត់សម្គាល់***៖ សូមចំណាំថាបណ្ណាល័យនេះគាំទ្រតែ transformers ***4.40.2***, សូមបញ្ជាក់កំណែ


### **5. បណ្ណាល័យ Python ផ្សេងៗ**


បង្កើត requirements.txt ហើយបន្ថែមមាតិកានេះ

```txt

notebook
numpy 
scipy 
scikit-learn 
matplotlib 
pandas 
pillow 
graphviz

```


### **6. ដំឡើង NVM**

ដំឡើង nvm នៅក្នុង Powershell 


```bash

winget install -e --id CoreyButler.NVMforWindows

```

ដំឡើង nodejs 18.20


```bash

nvm install 18.20.0

nvm use 18.20.0

```

### **7. ដំឡើងការគាំទ្រអភិវឌ្ឍន៍ Visual Studio Code**


```bash

npm install --global yo generator-code

```

អបអរសាទរ! អ្នកបានកំណត់ SDK ជោគជ័យ។ បន្ទាប់មក ដំណើរការទៅលើជំហានហាត់ប្រាណ។
