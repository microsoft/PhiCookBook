# **មេរៀនទី 3 - ដះដោន Phi-3-vision នៅលើសេវាកម្ម Azure Machine Learning**

យើងប្រើ NPU ដើម្បីបញ្ចប់ការដះដោនផលិតកម្មនៃកូដតំបន់ជាមូលដ្ឋាន ហើយបន្ទាប់មកយើងចង់ណែនាំសមត្ថភាពដើម្បីណែនាំ PHI-3-VISION តាមរយៈវា ដើម្បីឲ្យមានការបញ្ចេញកូដតាមរូបថត។

ក្នុងការណែនាំនេះ យើងអាចសាងសង់សេវាកម្ម Model As Service Phi-3 Vision នៅក្នុងសេវាកម្ម Azure Machine Learning បានយ៉ាងរហ័ស។

***សម្គាល់***៖ Phi-3 Vision ទាមទារបានអំណាចគណនា ដើម្បីបង្កើតមាតិកា بسرعةរហ័ស។ យើងត្រូវការអំណាចគណនាមេឃដើម្បីជួយឲ្យយើងសម្រេចបាននេះ។

***សម្គាល់***

1. ប៉ារ៉ាម៉ែត្រដើម្បីផ្ញើត្រូវតែមាន Authorization, azureml-model-deployment, និង Content-Type ។ អ្នកត្រូវពិនិត្យព័ត៌មានការដះដោន ដើម្បីទទួលបានវា។

2. ដើម្បីផ្ញើប៉ារ៉ាម៉ែត្រ Phi-3-Vision ត្រូវផ្ញើតំណរូបភាព។ សូមយោងទៅវិធីសាស្ត្រ GPT-4-Vision ក្នុងការផ្ញើប៉ារ៉ាម៉ែត្រ ដូចជា

```json

{
  "input_data":{
    "input_string":[
      {
        "role":"user",
        "content":[ 
          {
            "type": "text",
            "text": "You are a Python coding assistant.Please create Python code for image "
          },
          {
              "type": "image_url",
              "image_url": {
                "url": "https://ajaytech.co/wp-content/uploads/2019/09/index.png"
              }
          }
        ]
      }
    ],
    "parameters":{
          "temperature": 0.6,
          "top_p": 0.9,
          "do_sample": false,
          "max_new_tokens": 2048
    }
  }
}

```


3. ហៅ **/score** ដោយប្រើវិធីសាស្ដ្រប្រតិបត្តិការ Post

**អបអរសាទរ**! អ្នកបានបញ្ចប់ការដះដោន PHI-3-VISION យ៉ាងរហ័ស ហើយបានសាកល្បងរបៀបប្រើរូបភាពដើម្បីបង្កើតកូដ។ បន្ទាប់មក យើងអាចសាងសង់កម្មវិធីរួមគ្នាជាមួយ NPUs និងមេឃ។
