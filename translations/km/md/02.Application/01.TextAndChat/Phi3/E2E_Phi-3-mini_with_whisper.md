# Interactive Phi 3 Mini 4K Instruct Chatbot with Whisper

## ទិដ្ឋភាពទូទៅ

Interactive Phi 3 Mini 4K Instruct Chatbot គឺជាឧបករណ៍ដែលអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់​ធ្វើអន្តរកម្មជាមួយ Microsoft Phi 3 Mini 4K instruct demo ដោយប្រើការបញ្ចូលអត្ថបទ ឬសំឡេង។ chatbot អាចប្រើសម្រាប់បេសកកម្មជាច្រើន ដូចជាការបកប្រែ ការអាប់ដេតអាកាសធាតុ និងការប្រមូលព័ត៌មានទូទៅ។

### ចាប់ផ្ដើម

ដើម្បីប្រើ chatbot នេះ សូមអនុវត្តតាមការណែនាំខាងក្រោម៖

1. បើក [E2E_Phi-3-mini-4k-instruct-Whispser_Demo.ipynb](https://github.com/microsoft/Phi-3CookBook/blob/main/code/06.E2E/E2E_Phi-3-mini-4k-instruct-Whispser_Demo.ipynb) អ្នកថ្មី
2. នៅក្នុងផ្ទាំងសំខាន់នៃសៀវភៅកំណត់កំណត់បណ្ដាញ (notebook) អ្នកនឹងឃើញចំណុចអន្តរកម្ម chatbox ដែលមានប្រអប់បញ្ចូលអត្ថបទ និងប៊ូតុង "Send"។
3. ដើម្បីប្រើ chatbot ដោយផ្អែកលើអត្ថបទ គ្រាន់តេចុះបញ្ជីសារ​របស់អ្នកក្នុងប្រអប់បញ្ចូលអត្ថបទ ហើយចុចប៊ូតុង "Send"។ chatbot នឹងឆ្លើយតបទៅជាឯកសារ​សំឡេង ដែលអាចលេងបានផ្ទាល់ពីក្នុងសៀវភៅកំណត់កំណត់បណ្ដាញ។

**ចំណាំ**៖ ឧបករណ៍នេះទាមទារមិនត្រឹមតែ GPU ប៉ុណ្ណោះទេ ប៉ុន្តែថែមទាំងការចូលប្រើម៉ូឌែល Microsoft Phi-3 និង OpenAI Whisper ដែលប្រើសម្រាប់ការទទួលសំឡេង និងការបកប្រែផងដែរ។

### តម្រូវការបង្ហោះរូបភាព GPU

ដើម្បីបើកដំណើរការតេស្តនេះ អ្នកត្រូវការចំនួនអង្គចងចាំ GPU 12GB។

តម្រូវការអង្គចងចាំសម្រាប់បើកដំណើរការបង្ហាញ **Microsoft-Phi-3-Mini-4K instruct** នៅលើ GPU នឹងអាស្រ័យលើបញ្ហាច្រើន ដូចជាអំនាញអន្ដរកម្មខាងក្នុង (សំឡេង ឬអត្ថបទ), ភាសាដែលប្រើសម្រាប់បកប្រែ, ល្បឿនរបស់ម៉ូឌែល និងអង្គចងចាំដែលមាននៅលើ GPU។

ទូទៅ ម៉ូឌែល Whisper ត្រូវបានរចនាឡើងសម្រាប់ដំណើរការលើ GPU។ ចំនួនអង្គចងចាំ GPU អប្បបរមាដែលផ្ដល់អនុសាសន៍សម្រាប់ម៉ូឌែល Whisper គឺ 8 GB ប៉ុន្តែវាអាចគ្រប់គ្រងបានអង្គចងចាំធំជាងនេះ ប្រសិនបើត្រូវការ។

សំខាន់ណាស់ក្នុងការបញ្ជាក់ថា ការដំណើរការទិន្នន័យធំនឹងឬក៏អំពើសំណើមានចំនួនច្រើនលើម៉ូឌែល អាចតម្រូវអង្គចងចាំ GPU បន្ថែម និង/ឬបង្កការផ្ទុះកម្រិតសមត្ថភាព។ ការតេស្តករណីប្រើប្រាស់របស់អ្នកជាមួយការកំណត់ប្លង់ផ្សេងៗ ហើយត្រួតពិនិត្យការប្រើអង្គចងចាំគឺជាការផ្ដល់អនុសាសន៍ដ៏ល្អសម្រាប់កំណត់ការកំណត់មានភាពល្អឥតខ្ចោះសម្រាប់តម្រូវការពិសេសរបស់អ្នក។

## ឧទាហរណ៍ E2E សម្រាប់ Interactive Phi 3 Mini 4K Instruct Chatbot ជាមួយ Whisper

សៀវភៅកំណត់កំណត់បណ្ដាញដែលមានចំណងជើង [Interactive Phi 3 Mini 4K Instruct Chatbot with Whisper](https://github.com/microsoft/Phi-3CookBook/blob/main/code/06.E2E/E2E_Phi-3-mini-4k-instruct-Whispser_Demo.ipynb) បង្ហាញពីរបៀបប្រើ Microsoft Phi 3 Mini 4K instruct Demo ដើម្បីបង្កើតអត្ថបទពីអំនួតសំឡេង ឬអត្ថបទសរសេរ។ សៀវភៅកំណត់កំណត់បណ្ដាញនេះកំណត់មុខងារច្រើន៖

1. `tts_file_name(text)`: មុខងារនេះបង្កើតឈ្មោះឯកសារដោយផ្អែកលើអត្ថបទបញ្ចូលសម្រាប់រក្សាទុកឯកសារសំឡេងដែលបានផលិត។
1. `edge_free_tts(chunks_list,speed,voice_name,save_path)`: មុខងារនេះប្រើប្រាស់ Edge TTS API ដើម្បីបង្កើតឯកសារសំឡេងពីបញ្ជីអត្ថបទតូចៗ។ ប៉ារ៉ាម៉ែត្រ​បញ្ចូលគឺបញ្ជីអត្ថបទតូចៗ អត្រាសំឡេង ឈ្មោះសំលេង និងទីតាំងដែលរក្សារឯកសារសំឡេង។
1. `talk(input_text)`: មុខងារនេះបង្កើតឯកសារសំឡេងដោយប្រើ Edge TTS API ហើយរក្សាទុកឯកសារជាមួយឈ្មោះឯកសារខុសគ្នាក្នុងថត /content/audio។ ប៉ារ៉ាម៉ែត្រ​បញ្ចូលគឺអត្ថបទដែលត្រូវបម្លែងជាសំឡេង។
1. `run_text_prompt(message, chat_history)`: មុខងារនេះប្រើ Microsoft Phi 3 Mini 4K instruct demo ដើម្បីបង្កើតឯកសារសំឡេងពីសារ ដែលបន្ថែមចូលទៅក្នុងប្រវត្តិការសន្ទនា។
1. `run_audio_prompt(audio, chat_history)`: មុខងារនេះបម្លែងឯកសារសំឡេងទៅជាអត្ថបទ ដោយប្រើ Whisper model API ហើយផ្ដល់ទៅមុខងារ `run_text_prompt()`។
1. កូដបានចាប់ផ្ដើមកម្មវិធី Gradio ដែលអនុញ្ញាតឱ្យអ្នកប្រើប្រាស់ធ្វើអន្តរកម្មជាមួយ Phi 3 Mini 4K instruct demo ដោយវាយសារឬផ្ទុកឯកសារសំឡេង។ លទ្ធផលត្រូវបង្ហាញក្នុងលំដាប់សារអត្ថបទ​នៅក្នុងកម្មវិធី។

## ការដោះស្រាយបញ្ហា

ការដំឡើងកម្មវិធីបើកបរ Cuda GPU

1. ប្រាកដថាកម្មវិធី Linux របស់អ្នកទាន់សម័យ

    ```bash
    sudo apt update
    ```

1. ដំឡើងកម្មវិធីបើកបរ Cuda

    ```bash
    sudo apt install nvidia-cuda-toolkit
    ```

1. ចុះបញ្ជីទីតាំងកម្មវិធីបើកបររបស់ cuda

    ```bash
    echo /usr/lib64-nvidia/ >/etc/ld.so.conf.d/libcuda.conf; ldconfig
    ```

1. ពិនិត្យទំហំអង្គចងចាំ Nvidia GPU (តម្រូវការ 12GB អង្គចងចាំ GPU)

    ```bash
    nvidia-smi
    ```

1. ឃ្លាតផ្ទុករំលាយ៖ ប្រសិនបើអ្នកប្រើ PyTorch អ្នកអាចហៅ torch.cuda.empty_cache() ដើម្បីដោះសោធាតុអង្គចងចាំដែលមិនប្រើដោយសារពេលវេលា ដូច្នេះអាចប្រើបានសម្រាប់កម្មវិធី GPU ផ្សេងទៀត

    ```python
    torch.cuda.empty_cache() 
    ```

1. ពិនិត្យរឿង Nvidia Cuda

    ```bash
    nvcc --version
    ```

1. ធ្វើបេសកកម្មខាងក្រោម ដើម្បីបង្កើត token នៅលើ Hugging Face។

    - ទៅកាន់ [ទំព័រតំរូវការ Token Hugging Face](https://huggingface.co/settings/tokens?WT.mc_id=aiml-137032-kinfeylo) ។
    - ជ្រើស **New token**។
    - បញ្ចូលឈ្មោះគម្រោងដែលអ្នកចង់ប្រើ។
    - ជ្រើសប្រភេទ **Type** ទៅជា **Write**។

> [!NOTE]
>
> បើអ្នកជួបកំហុសដូចខាងក្រោម៖
>
> ```bash
> /sbin/ldconfig.real: Can't create temporary cache file /etc/ld.so.cache~: Permission denied 
> ```
>
> ដើម្បីដោះសោនេះ សូមវាយពាក្យបញ្ជាដូចខាងក្រោមនៅក្នុងទម្រង់ពាក្យបញ្ជារ​របស់អ្នក។
>
> ```bash
> sudo ldconfig
> ```
