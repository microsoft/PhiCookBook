# Phi-3.5-Instruct WebGPU RAG Chatbot

## ការបង្ហាញសម្រាប់បង្ហាញពី WebGPU និងរចនាប័ទ្ម RAG

រចនាប័ទ្ម RAG ជាមួយម៉ូដែល Phi-3.5 Onnx Hosted អាចប្រើប្រាស់វិធីសាស្រ្ត Retrieval-Augmented Generation ដែលបញ្ចូលកម្លាំងរបស់ម៉ូដែល Phi-3.5 ជាមួយការផ្ទុក ONNX សម្រាប់ការប្រើប្រាស់ AI ប្រសិទ្ធិភាព។ រចនាប័ទ្មនេះមានតួនាទីសំខាន់ក្នុងការកែសម្រួលម៉ូដែលសម្រាប់ភារកិច្ចជាក់លាក់តាមដែនការងារ ជួយផ្តល់នូវការរួមបញ្ចូលគុណភាព តម្លៃថោក និងការយល់ដឹងអំពីបរិបទវែង។ វាជាផ្នែកមួយនៃកញ្ចប់ Azure AI ដែលផ្តល់ជូននូវម៉ូដែលជាច្រើនដែលងាយស្រួលស្វែងរក សាកល្បង និងប្រើប្រាស់ ដើម្បីបំពេញតម្រូវការប្តូរតាមឧស្សាហកម្មនានា។

## តើ WebGPU ជាអ្វី  
WebGPU គឺជាសរសេរបច្ចេកវិទ្យាគ្រប់គ្រងក្រាហ្វិកបណ្ដាញទំនើប ដែលរចនាឡើងដើម្បីផ្តល់ការចូលដំណើរការជាបន្ទាត់ទៅឧបករណ៍បន្ទះប្រើប្រាស់ក្រាហ្វិក (GPU) ពីកម្មវិធីរុករកបណ្ដាញ។ វាមានគោលបំណងដើម្បីជំនួស WebGL ដោយផ្តល់នូវការកែលម្អសំខាន់ៗ៖

1. **ឆ្គាប់នឹង GPU ទំនើបៗ**: WebGPU ត្រូវបានបង្កើតឡើងដើម្បីធ្វើការជាមួយរចនាសម្ព័ន្ធ GPU លំនាំថ្មីៗ ដោយប្រើប្រព័ន្ធ API ដូចជា Vulkan, Metal, និង Direct3D 12។
2. **កម្រិតបង្ហាញលឿនជាងមុន**: វគាំទ្រការគណនាថាមពលទូទៅនៃ GPU និងប្រតិបត្តិការលឿនជាងមុន ដែលធ្វើឲ្យវាសមរម្យសម្រាប់ការបង្ហាញក្រាហ្វិក និងភារកិច្ចរៀនម៉ាស៊ីន។
3. **មុខងារល្អប្រសើរជាងមុន**: WebGPU ផ្តល់នូវការចូលដំណើរការទៅមុខងារលំអិតរបស់ GPU បានច្រើន ជួយអោយអាចធ្វើបានការបង្ហាញក្រាហ្វិក និងទម្រង់ការងារគណនាពហុភាព។
4. **កាត់បន្ថយការងារលើ JavaScript**: ដោយផ្ទុកការងារច្រើនទៅខាង GPU, WebGPU កាត់បន្ថយការបន្ទុកលើ JavaScript បានយ៉ាងច្រើន នាំអោយមានការសម្រួលល្អ និងប្រសិទ្ធភាពកាន់តែប្រសើរ។

WebGPU ត្រូវបានគាំទ្រនៅក្នុងកម្មវិធីរុករកដូចជា Google Chrome ហើយកំពុងបន្តកសាងការគាំទ្រទៅកាន់វេទិកាផ្សេងទៀត។

### 03.WebGPU  
បរិយាកាសត្រូវការ៖

**កម្មវិធីរុករកគាំទ្រ:**  
- Google Chrome 113+  
- Microsoft Edge 113+  
- Safari 18 (macOS 15)  
- Firefox Nightly។  

### បើក WebGPU៖

- នៅក្នុង Chrome/Microsoft Edge

បើកការបិទបញ្ជា `chrome://flags/#enable-unsafe-webgpu` ។

#### បើកកម្មវិធីរុករករបស់អ្នក៖  
បើក Google Chrome ឬ Microsoft Edge ។

#### ចូលទៅកាន់ទំព័របិទបញ្ជា៖  
នៅក្នុងបន្ទាត់អាសយដ្ឋាន សរសេរ `chrome://flags` ហើយចុច Enter ។

#### ស្វែងរកបិទបញ្ជា៖  
នៅក្នុងប្រអប់ស្វែងរកខាងលើសរសេរ 'enable-unsafe-webgpu' ។

#### បើកបិទបញ្ជា៖  
ស្វែងរកប៊្លុក #enable-unsafe-webgpu នៅក្នុងបញ្ជីលទ្ធផល ។

ចុចម៉ឺនុយជម្រើសខាងលើ វាយជម្រើស Enabled ។

#### ចាប់ផ្តើមកម្មវិធីរុករករបស់អ្នកម្ដងទៀត៖

បន្ទាប់ពីបើកបិទបញ្ជា នោះអ្នកត្រូវចាប់ផ្តើមកម្មវិធីរុករកឡើងវិញ ដើម្បីទទួលបានការផ្លាស់ប្តូរ។ ចុចប៊ូតុង Relaunch នៅខាងក្រោមទំព័រ។

- សម្រាប់ Linux, បើកកម្មវិធីរុករកជាមួយ `--enable-features=Vulkan` ។  
- Safari 18 (macOS 15) មាន WebGPU បើក​ផ្ទាល់​ដើម។  
- នៅក្នុង Firefox Nightly, បញ្ចូល about:config នៅក្នុងបន្ទាត់អាសយដ្ឋាន ហើយបើក `set dom.webgpu.enabled to true` ។

### ការកំណត់ GPU សម្រាប់ Microsoft Edge  

នេះជាជំហានសម្រាប់កំណត់ GPU មានសមត្ថភាពខ្ពស់សម្រាប់ Microsoft Edge នៅលើ Windows ៖

- **បើក Settings:** ចុចម៉ឺនុយ Start ហើយជ្រើស Settings ។  
- **System Settings:** ទៅកាន់ System ហើយបន្ទាប់ទៅ Display ។  
- **ការកំណត់ក្រាហ្វិក:** ផ្លាស់បន្ទាត់ចុះក្រោម ហើយចុច Graphics settings ។  
- **ជ្រើសកម្មវិធី:** ក្រោម "Choose an app to set preference," ជ្រើស Desktop app ហើយបន្ទាប់ Browse ។  
- **ជ្រើស Edge:** ទៅកាន់ថតដាក់កម្មវិធី Edge (ជាធម្មតា `C:\Program Files (x86)\Microsoft\Edge\Application`) ហើយជ្រើស `msedge.exe` ។  
- **កំណត់ចំណាប់អារម្មណ៍:** ចុច Options, ជ្រើស High performance ហើយបន្ទាប់ចុច Save ។  
នេះនឹងធានាថា Microsoft Edge ប្រើ GPU សមត្ថភាពខ្ពស់របស់អ្នកសម្រាប់ប្រសិទ្ធភាពល្អ។  
- **ចាប់ផ្តើមឡើងវិញ** ម៉ាស៊ីនរបស់អ្នកដើម្បីការកំណត់នេះមានប្រសិទ្ធភាព។
