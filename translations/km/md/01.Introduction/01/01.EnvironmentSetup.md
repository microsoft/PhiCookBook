# ចាប់ផ្ដើមជាមួយ Phi-3 នៅក្នុងម៉ាស៊ីនបម្រើផ្ទាល់ខ្លួន

មគ្គុទេសក៍នេះនឹងជួយអ្នកបង្កើតបរិស្ថានផ្ទាល់ខ្លួនដើម្បីបញ្ចេញម៉ូដែល Phi-3 ដោយប្រើ Ollama។ អ្នកអាចបញ្ជូនម៉ូដែលនេះជាច្រើនវិធីផ្សេងៗ រួមមានការប្រើប្រាស់ GitHub Codespaces, VS Code Dev Containers, ឬបរិស្ថានផ្ទាល់ខ្លួនរបស់អ្នក។

## ការដំឡើងបរិស្ថាន

### GitHub Codespaces

អ្នកអាចបញ្ចូលទំព័រតំណរនេះដោយប្រើ GitHub Codespaces។ ប៊ូតុងនឹងបើកបង្ហាញ VS Code នៅលើបណ្តាញក្នុងកម្មវិធីបើកប្រាប់របស់អ្នក៖

1. បើកគំរូ (នេះអាចចំណាយពេលប៉ុន្មាននាទី)៖

    [![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/microsoft/phi-3cookbook)

2. បើកបង្អួចឆាកពាក្យបញ្ជា

### VS Code Dev Containers

⚠️ ជម្រើសនេះនឹងដំណើរការត្រឹមតែបើកពីព្រោះប្រព័ន្ធ Docker Desktop របស់អ្នកបានចំណាយ RAM យ៉ាងហោចណាស់ 16 GB។ ប្រសិនបើអ្នកមាន RAM តិចជាង 16 GB អ្នកអាចសាកល្បងជម្រើស [GitHub Codespaces](#github-codespaces) ឬ [កំណត់បរិស្ថានផ្ទាល់ខ្លួន](#បរិស្ថានផ្ទាល់ខ្លួន)។

ជម្រើសមួយទៀតគឺ VS Code Dev Containers ដែលនឹងបើកគម្រោងនៅ VS Code នៅក្នុងម៉ាស៊ីនបម្រើផ្ទាល់ខ្លួនរបស់អ្នកដោយប្រើ [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)៖

1. ចាប់ផ្តើម Docker Desktop (ដំឡើងបើមិនមាន)
2. បើកគម្រោង៖

    [![Open in Dev Containers](https://img.shields.io/static/v1?style=for-the-badge&label=Dev%20Containers&message=Open&color=blue&logo=visualstudiocode)](https://vscode.dev/redirect?url=vscode://ms-vscode-remote.remote-containers/cloneInVolume?url=https://github.com/microsoft/phi-3cookbook)

3. នៅក្នុងបង្អួច VS Code ដែលបានបើក ប្រសិនបើឯកសារគម្រោងបង្ហាញឡើង (នេះអាចចំណាយពេលប៉ុន្មាននាទី) បើកបង្អួចឆាកពាក្យបញ្ជា។
4. បន្តជាមួយ [ជំហានបញ្ចេញ](#deployment)

### បរិស្ថានផ្ទាល់ខ្លួន

1. សូមប្រាកដថាបណ្ដុំឧបករណ៍ខាងក្រោមត្រូវបានដំឡើង៖

    * [Ollama](https://ollama.com/)
    * [Python 3.10+](https://www.python.org/downloads/)
    * [OpenAI Python SDK](https://pypi.org/project/openai/)

## សាកល្បងម៉ូដែល

1. ស្នើ Ollama ដើម្បីទាញយកនិងបញ្ចេញម៉ូដែល phi3:mini៖

    ```shell
    ollama run phi3:mini
    ```

    វានឹងចំណាយពេលប៉ុន្មាននាទីក្នុងការទាញយកម៉ូដែល។

2. ពេលអ្នកឃើញ "success" នៅក្នុងចេញផល ត្រូវបានគេអាចផ្ញើសារទៅម៉ូដែលនោះពីបញ្ជារ។

    ```shell
    >>> Write a haiku about hungry hippos
    ```

3. បន្ទាប់ពីប៉ុន្មានវិនាទី អ្នកគួរតែឃើញចរន្តចម្លើយពីម៉ូដែល។

4. ដើម្បីស្វែងយល់អំពីបច្ចេកទេសផ្សេងៗដែលបានប្រើរួមជាមួយម៉ូដែលភាសា បើកសៀវភៅ Python [ollama.ipynb](../../../code/01.Introduce/ollama.ipynb) ហើយបញ្ចេញកម្មវិធីក្នុងកោសិកា ខុសប្រសិនបើអ្នកបានប្រើម៉ូដែលផ្សេងពី 'phi3:mini' សូមផ្លាស់ប្តូរ `MODEL_NAME` នៅក្នុងកោសិកាលើកដំបូង។

5. ដើម្បីមានការសន្ទនា​ជាមួយម៉ូដែល phi3:mini ពី Python សូមបើកឯកសារ Python [chat.py](../../../../../code/01.Introduce/chat.py) ហើយចាប់ផ្តើមបញ្ចេញវា។ អ្នកអាចផ្លាស់ប្តូរ `MODEL_NAME` នៅខាងលើឯកសារតាមតម្រូវការ ហើយអ្នកក៏អាចកែសម្រួលសារ របស់ប្រព័ន្ធ ឬបញ្ចូលឧទាហរណ៍បន្តបន្ទាប់បន្ថែមបានប្រសិនបើចង់បាន។
