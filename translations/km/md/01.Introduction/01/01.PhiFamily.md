# គ្រួសារ Phi របស់ Microsoft

ម៉ូដែល Phi គឺជាម៉ូដែលភាសាតូចដែលមានសមត្ថភាពខ្ពស់ និងមានតម្លៃសមរម្យបំផុត (SLMs) ដែលមានស្រាប់ ដោយអាចលើកដំណើរការម៉ូដែលដែលមានទំហំដូចគ្នានិងទំហំបន្ទាប់បានល្អជាងគេ ក្នុងលំហនានារួមមានភាសា ការពិចារណា ការសរសេរកូដ សំឡេង មើលឃើញ និងគណិតវិទ្យា។ ការចេញផ្សាយនេះបានពង្រីកជម្រើសម៉ូដែលមានគុណភាពខ្ពស់សម្រាប់អតិថិជន ផ្តល់ជម្រើសដែលអាចប្រើប្រាស់បានជាច្រើនសម្រាប់បង្កើត និងសាងសង់កម្មវិធី AI បង្កើត។

គ្រួសារ Phi ចាប់ផ្តើមជាមួយ Phi-1 សម្រាប់ ការបង្កើតកូដ Python បន្តទៅ Phi-1.5 /2 ដែលផ្អែកលើការបញ្ចប់អត្ថបទ និងការសន្ទនា, Phi-3-mini/small/medium-instruct និង Phi-3.5/4-mini-instruct, ហើយបន្តអភិវឌ្ឍទៅ Phi-3/3.5-vision សម្រាប់វិស័យមើលឃើញ, Phi-4 ដែលផ្អែកលើការពិចារណាខ្លាំង, Phi-3.5-MoE សម្រាប់ MoE, ហើយឥឡូវយើងមានម៉ូដែលម៉ូដាល់ពេញលេញ Phi-4-multimodal។ តាមរយៈឃ្លាំងទិន្នន័យដែលមានគុណភាពខ្ពស់ លទ្ធផលពិសោធន៍អាចបណ្តុះបណ្តាលឲ្យស្មើស្មើនឹងម៉ូដែលដែលមានប៉ារ៉ាម៉ែត្ររៀនច្រើនជាង។
