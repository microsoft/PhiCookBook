### Guidance-AI នឹងម៉ូឌែល Phi ជាសេវាកម្ម (MaaS)
ពួកយើងកំពុងនាំមក [Guidance](https://github.com/guidance-ai/guidance) ទៅកាន់ចុងផ្ដាច់ Phi-3.5-mini serverless endpoint ដែលមាននៅ Microsoft Foundry ដើម្បីធ្វើឱ្យលទ្ធផលមានការព្យាករណ៍បានច្បាស់តាមរយៈការកំណត់រចនាសម្ព័ន្ធត្រូវសមស្របសម្រាប់កម្មវិធីមួយ។ ជាមួយ Guidance អ្នកអាចដកហូតការបន្តលើកថ្លៃថ្លាពេក ហើយអាច, ឧទាហរណ៍, ឈប់ម៉ូឌែលឲ្យជ្រើសរើសពីបញ្ជីដែលបានកំណត់រួច (ឧ. កូដវេជ្ជសាស្ត្រ), កំណត់លទ្ធផលឲ្យបានត្រឹមតែរាប់បញ្ជីពីបរិបទដែលផ្ដល់ជូន ឬបន្ដតាម regex មួយណាមួយ។ Guidance នាំម៉ូឌែលឆាប់ៗតាម token ក្នុងចំណុចនៃការបញ្ចៀសមួយ បន្តបន្ថយការចំណាយ និងពេលវេលាប្រើប្រាស់ 30-50% ដែលធ្វើឱ្យវាជាការបន្ថែមមានតម្លៃនិងប្លែកសម្រាប់ [Phi-3-mini serverless endpoint](https://aka.ms/try-phi3.5mini)។

## [**Guidance-AI**](https://github.com/guidance-ai/guidance) គឺជាស៊ឹកវ៉េសដែលត្រូវបានរចនាឡើងដើម្បីជួយអ្នកអភិវឌ្ឍ បង្កើតនិងដាក់បញ្ចូលម៉ូឌែល AI យ៉ាងមានប្រសិទ្ធភាព។ វាផ្តោតលើការផ្ដល់ឧបករណ៍ និងអនុវត្តន៍ល្អបំផុតសម្រាប់ការ បង្កើតកម្មវិធី AI ដែលរឹងមាំ។ 

ពេលភ្ជាប់ជាមួយ **Phi Models as a Service (MaaS)** វាប្រាថ្នាផ្ដល់ដំណោះស្រាយខ្លាំងសម្រាប់ដាក់បញ្ចូលម៉ូឌែលភាសាសង្ខេប (SLMs) ដែលមានការចំណាយទាប និងមានប្រសិទ្ធភាពខ្ពស់។

**Guidance-AI** គឺជាស៊ឹកវ៉េសកម្មវិធីដែលរចនាឡើងដើម្បីជួយអ្នកអភិវឌ្ឍគ្រប់គ្រងនិងដឹកនាំម៉ូឌែលភាសាធំ (LLMs) បានប្រសើរជាងមុន។ វាអនុញ្ញាតឲ្យធ្វើរចនាសម្ព័ន្ធលទ្ធផលបានត្រឹមត្រូវ កាត់បន្ថយពេលយឺត និងកម្លាំងសំរាប់ចំណាយប្រាក់ ប្រៀបធៀបនឹងវិធីបង្ហាញផ្សារភ្ជាប់បែបប្រពៃណី ឬការបង្ហាត់បន្ត។

### លក្ខណៈសំខាន់ៗនៃ Guidance-AI៖
- **ការគ្រប់គ្រងប្រសិទ្ធភាព**៖ អនុញ្ញាតឲ្យអ្នកអភិវឌ្ឍគ្រប់គ្រងរបៀបដែលម៉ូឌែលភាសាផលិតអត្ថបទ ដើម្បីធានាលទ្ធផលដែលមានគុណភាពខ្ពស់ និងពាក់ព័ន្ធ។
- **ការបន្ថយចំណាយ និងពេលយឺត**៖ បង្កើតការផលិតឲ្យមានប្រសិទ្ធភាពចំណាយនិងរហ័សជាងមុន។
- **ការរួមបញ្ចូលបត់បែន**៖ ធ្វើការជាមួយ backend ផ្សេងៗ រួមមាន Transformers, llama.cpp, AzureAI, VertexAI និង OpenAI។
- **រចនាសម្ព័ន្ធលទ្ធផលសម្បូរ**៖ គាំទ្ររចនាសម្ព័ន្ធលទ្ធផលស្មុគស្មាញ ដូចជាការជញ្ជក់លក្ខខណ្ឌ, លំហូរនិងការប្រើប្រាស់ឧបករណ៍ ដែលធ្វើឲ្យការផលិតលទ្ធផលច្បាស់លាស់ និងអាចបកស្រាយបាន។
- **ភាពសមថៈ**៖ អនុញ្ញាតឲ្យកម្មវិធី Guidance មួយត្រូវបានអនុវត្តលើ backend ផ្សេងៗបានច្រើន បង្កើនភាពបត់បែន និងងាយស្រួលប្រើ។

### ឧទាហរណ៍ករណីប្រើប្រាស់៖
- **ការផលិតមានកំណត់**៖ ប្រើបច្ចេកទេស regex និងវេយ្យាករណ៍មិនមានបរិបទ ដើម្បីណែនាំលទ្ធផលរបស់ម៉ូឌែល។
- **រួមបញ្ចូលឧបករណ៍**៖ ដំណើរការគ្រប់គ្រង និងការផលិតដោយស្វ័យប្រវត្តិ ដូចជា ការប្រើកលគណនាងក្នុងភារកិច្ចបង្កើតអត្ថបទ។

សម្រាប់ព័ត៌មានលម្អិតបន្ថែម និងឧទាហរណ៍ អ្នកអាចពិនិត្យមើល [Guidance-AI GitHub repository](https://github.com/guidance-ai/guidance)។

### លក្ខណៈសំខាន់ៗនៃម៉ូឌែល Phi៖
1. **មានតម្លៃសមរម្យ**៖ រចនាឡើងដើម្បីមានតម្លៃសមរម្យ និងថែទាំសមត្ថភាពខ្ពស់។
2. **ពេលប្រតិបត្តិការថយក្រោម**៖ ល្អសម្រាប់កម្មវិធីពិតប្រាកដត្រូវការឆ្លើយតបរហ័ស។
3. **ភាពបត់បែន**៖ អាចផ្សព្វផ្សាយក្នុងបរិយាកាសផ្សេងៗ រួមទាំង cloud, edge និង offline។
4. **ផ្ទាល់ខ្លួនការ**៖ ម៉ូឌែលអាចកែប្រែការពេញលេញជាមួយទិន្នន័យជាពិសេសបន្ទាប់ដើម្បីបង្កើនសមត្ថភាព។
5. **សុវត្ថិភាព និងការចង្អុលបង្ហាញ**៖ បានសង់ឡើងជាមួយគោលការណ៍ AI របស់ Microsoft ដែលធានាការទទួលខុសត្រូវ, ភាពច្បាស់លាស់, ភាពយុត្តិធម៌, ការសម្របសម្រួល, សុវត្ថិភាព, ភាពឯកជន និងការចូលរួម។

### ម៉ូឌែល Phi ជាសេវាកម្ម (MaaS)៖
ម៉ូឌែល Phi អាចចូលប្រើបានតាមប្រព័ន្ធគិតប្រាក់ pay-as-you-go តាម API ព្យាករណ៍ ថែមទាំងងាយស្រួលផ្ដោតផ្ដល់ចូលកម្មវិធីរបស់អ្នកដោយគ្មានការចំណាយដើមធំៗ។

### ចាប់ផ្តើមប្រើ Phi-3៖
ដើម្បីចាប់ផ្តើមប្រើម៉ូឌែល Phi អ្នកអាចស្វែងរកទៅកាន់ [Azure AI model catalog](https://ai.azure.com/explore/models) ឬ GitHub Marketplace Models](https://github.com/marketplace/models) ដែលផ្ដល់ម៉ូឌែលដែលបានរចនាស្រេច និងអាចកែប្រែបន្ថែមបាន។ លើសពីនេះ អ្នកអាចប្រើឧបករណ៍ដូចជា [Microsoft Foundry](https://ai.azure.com) ដើម្បីអភិវឌ្ឍនិងដាក់បញ្ចូលកម្មវិធី AI របស់អ្នក។
