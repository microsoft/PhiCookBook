Phi je séria open source AI modelov vyvinutých spoločnosťou Microsoft.

Phi je v súčasnosti najvýkonnejší a najnákladovo efektívnejší malý jazykový model (SLM), s veľmi dobrými benchmarkmi v multi-jazyku, odôvodňovaní, generovaní textu/chatovania, kódovaní, obrázkoch, zvuku a iných scenároch.

Phi môžete nasadiť do cloudu alebo na edge zariadenia a môžete jednoducho vytvárať generatívne AI aplikácie s obmedzeným výpočtovým výkonom.

Postupujte podľa týchto krokov na začatie používania týchto zdrojov:
1. **Forknite repozitár**: Kliknite [![Forky na GitHub](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Fork)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)

>

> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Toto vám poskytne všetko potrebné na dokončenie kurzu s oveľa rýchlejším sťahovaním.

## Zodpovedná AI

Microsoft sa zaväzuje pomáhať našim zákazníkom používať naše AI produkty zodpovedne, zdieľať naše poznatky a budovať partnerstvá založené na dôvere prostredníctvom nástrojov ako Transparency Notes a Impact Assessments. Mnohé z týchto zdrojov nájdete na [https://aka.ms/RAI](https://aka.ms/RAI).
Prístup spoločnosti Microsoft k zodpovednej AI je založený na našich AI princípoch spravodlivosti, spoľahlivosti a bezpečnosti, ochrany súkromia a bezpečnosti, inkluzívnosti, transparentnosti a zodpovednosti.

Modely veľkého rozsahu pre prirodzený jazyk, obraz a reč – ako tie použité v tejto vzorke – sa môžu potenciálne správať nespravodlivo, nespoľahlivo alebo urážlivo, čím môžu spôsobiť škody. Prosím, prečítajte si [Poznámku o transparentnosti služby Azure OpenAI](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text), aby ste boli informovaní o rizikách a obmedzeniach.

Odporúčaným prístupom na zníženie týchto rizík je zahrnúť do vašej architektúry bezpečnostný systém, ktorý dokáže detegovať a zabrániť škodlivému správaniu. [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) poskytuje nezávislú vrstvu ochrany, schopnú detegovať škodlivý obsah vytvorený používateľmi a AI v aplikáciách a službách. Azure AI Content Safety zahŕňa textové a obrazové API, ktoré vám umožňujú detegovať škodlivý obsah. V rámci Microsoft Foundry vám služba Content Safety umožňuje prezerať, skúmať a skúšať ukážkový kód na detekciu škodlivého obsahu v rôznych modalitách. Nasledujúca [rýchla dokumentácia na začiatok](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) vás prevedie vytváraním požiadaviek na službu.

Ďalším aspektom, ktorý je potrebné zohľadniť, je celkový výkon aplikácie. Pri multimodálnych a multimodelových aplikáciách považujeme výkon za to, že systém pracuje tak, ako očakávate vy aj vaši používatelia, vrátane toho, že nevytvára škodlivé výstupy. Je dôležité vyhodnotiť výkon vašej celej aplikácie pomocou [hodnotiacich nástrojov výkonnosti a kvality a rizika a bezpečnosti](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in). Tiež máte možnosť vytvárať a hodnotiť pomocou [vlastných hodnotiacich nástrojov](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators).

Vašu AI aplikáciu môžete hodnotiť vo vývojovom prostredí pomocou [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html). Na základe testovacej dátovej množiny alebo cieľa sú vaše generácie generatívnej AI aplikácie kvantitatívne merané vestavnými hodnotiacimi nástrojmi alebo vlastnými hodnotiacimi nástrojmi podľa vášho výberu. Na začiatok práce so SDK na hodnotenie azure ai, aby ste vyhodnotili váš systém, môžete sledovať [rýchlu príručku](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk). Po vykonaní hodnotiaceho behu môžete [vizualizovať výsledky v Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
