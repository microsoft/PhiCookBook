Phi je séria open source AI modelov vyvinutých spoločnosťou Microsoft.

Phi je momentálne najvýkonnejší a nákladovo najefektívnejší malý jazykový model (SLM), s veľmi dobrými výsledkami v oblasti viacjazyčnosti, uvažovania, generovania textu/chatov, kódovania, obrázkov, zvuku a ďalších scenárov.

Phi môžete nasadiť do cloudu alebo na edge zariadenia a môžete jednoducho budovať generatívne AI aplikácie s obmedzenou výpočtovou silou.

Postupujte podľa týchto krokov, aby ste sa naučili používať tieto zdroje:
1. **Vytvorte Fork Repozitára**: Kliknite na [![Rozdvojenia na GitHub](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Rozdvojenie)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)
2. **Naklonujte Repozitár**:   `git clone https://github.com/microsoft/PhiCookBook.git`
3. [**Pridajte sa do Microsoft AI Discord komunity a stretávajte odborníkov a vývojárov**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

>
> Tento repozitár obsahuje viac ako 50 jazykových prekladov, čo výrazne zväčšuje veľkosť stiahnutia. Ak chcete klonovať bez prekladov, použite sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Týmto získate všetko, čo potrebujete na dokončenie kurzu s oveľa rýchlejším stiahnutím.

Phi je séria open source AI modelov vyvinutých spoločnosťou Microsoft.

Phi je momentálne najvýkonnejší a najnákladovo efektívny malý jazykový model (SLM) s veľmi dobrými výsledkami v multijazyčnosti, uvažovaní, generovaní textu/chatov, programovaní, obrázkoch, audiu a ďalších scenároch.

Model Phi môžete nasadiť do cloudu alebo na okrajové zariadenia a môžete ľahko vytvárať generatívne AI aplikácie aj s obmedzeným výpočtovým výkonom.

## Zodpovedná AI

Microsoft sa zaväzuje pomáhať našim zákazníkom používať naše AI produkty zodpovedne, zdieľať naše poznatky a budovať partnerstvá založené na dôvere prostredníctvom nástrojov ako Transparency Notes a Impact Assessments. Mnohé z týchto zdrojov je možné nájsť na [https://aka.ms/RAI](https://aka.ms/RAI).
Prístup Microsoftu k zodpovednej AI je založený na našich AI princípoch spravodlivosti, spoľahlivosti a bezpečnosti, ochrane súkromia a bezpečnosti, inkluzívnosti, transparentnosti a zodpovednosti.

Veľké modely prirodzeného jazyka, obrazu a reči - ako tie používané v tomto príklade - môžu potenciálne konať spôsobmi, ktoré sú nespravodlivé, nespoľahlivé alebo urážlivé, čo môže viesť k škodám. Prosím, konzultujte [Transparency note služby Azure OpenAI](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text), aby ste boli informovaní o rizikách a obmedzeniach.

Odporúčaným prístupom na zníženie týchto rizík je zahrnúť do architektúry bezpečnostný systém, ktorý dokáže detekovať a predchádzať škodlivému správaniu. [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) poskytuje nezávislú vrstvu ochrany, schopnú detegovať škodlivý obsah vytvorený používateľom alebo AI v aplikáciách a službách. Azure AI Content Safety zahŕňa API pre text a obraz, ktoré vám umožňujú detegovať škodlivý materiál. V rámci Microsoft Foundry služba Content Safety umožňuje prezerať, skúmať a vyskúšať ukážkové kódy na detekciu škodlivého obsahu v rôznych modalitách. Nasledujúca [rýchla príručka](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) vás prevedie vykonávaním požiadaviek na túto službu.

Ďalším aspektom, ktorý treba zohľadniť, je celkový výkon aplikácie. Pri multimodálnych a multimodelových aplikáciách sa výkon považuje za to, že systém funguje podľa očakávania vás a vašich používateľov, vrátane toho, že nevytvára škodlivé výstupy. Je dôležité zhodnotiť výkon vašej aplikácie pomocou [hodnotiacich nástrojov výkonu a kvality a rizika a bezpečnosti](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in). Máte tiež možnosť vytvárať a vykonávať hodnotenia pomocou [vlastných hodnotiacich nástrojov](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators).

Svoju AI aplikáciu môžete hodnotiť vo svojom vývojovom prostredí pomocou [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html). Na základe testovacej dátovej sady alebo cieľa sa generácie vašej generatívnej AI aplikácie kvantitatívne merajú pomocou vstavaných alebo vlastných hodnotiacich nástrojov podľa vášho výberu. Ak chcete začať používať azure ai evaluation sdk na hodnotenie vášho systému, môžete sledovať [rýchlu príručku](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk). Po spustení hodnotiaceho behu môžete [vizualizovať výsledky v Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
