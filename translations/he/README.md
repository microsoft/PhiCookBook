פאי היא סדרת דגמי בינה מלאכותית בקוד פתוח שפיתחה מיקרוסופט. 

פאי היא כיום דגם שפה קטן (SLM) החזק והיעיל ביותר מבחינת עלות, עם מדדים טובים מאוד במולטילינגואלי, היסק, יצירת טקסט/צ'אט, קידוד, תמונות, אודיו וסצנריואים נוספים. 

ניתן לפרוס את פאי בענן או במכשירי קצה, וניתן לבנות בקלות יישומי בינה מלאכותית יצירתיים עם כוח חישובי מוגבל.

עקבו אחרי הצעדים הבאים כדי להתחיל להשתמש במשאב זה:
1. **יצירת מזלג למאגר**: לחצו על [![מזלגות GitHub](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Fork)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)
2. **שכפול המאגר**: `git clone https://github.com/microsoft/PhiCookBook.git`
3. [**הצטרפו לקהילת מיקרוסופט AI בדיסקורד ופגשו מומחים ומפתחים נוספים**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> זה נותן לכם את כל מה שצריך כדי להשלים את הקורס במהירות הורדה גבוהה יותר.

## AI אחראי 

Microsoft מחויבת לסייע ללקוחותינו להשתמש במוצרי ה-AI שלנו באחריות, לשתף את הלימודים שלנו ולבנות שותפויות מבוססות אמון באמצעות כלים כמו הערות שקיפות והערכות השפעה. משאבים רבים אלה ניתן למצוא ב-[https://aka.ms/RAI](https://aka.ms/RAI).
הגישה של Microsoft ל-AI אחראי מבוססת על עקרונות ה-AI שלנו של יושר, אמינות ובטיחות, פרטיות ואבטחה, הכללה, שקיפות ואחריות.

מודלים רחבי היקף של שפה טבעית, תמונה ודיבור - כמו אלה שבהם משתמשים במדגם זה - יכולים להתנהג בדרכים שאינן הוגנות, לא אמינות או פוגעניות, ובכך לגרום לנזקים. אנא עיינו ב-[הערת השקיפות של שירות Azure OpenAI](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) כדי להתעדכן בסיכונים ומגבלות.

הגישה המומלצת להפחתת סיכונים אלו היא לכלול מערכת בטיחות בארכיטקטורה שלך שיכולה לזהות ולמנוע התנהגות מזיקה. [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) מספקת שכבת הגנה עצמאית, המסוגלת לזהות תכנים מזיקים שנוצרו על ידי משתמשים או בינה מלאכותית באפליקציות ובשירותים. Azure AI Content Safety כוללת ממשקי API לטקסט ותמונה המאפשרים לזהות חומר מזיק. בתוך Microsoft Foundry, שירות Content Safety מאפשר לך לצפות, לחקור ולנסות דוגמאות קוד לזיהוי תוכן מזיק במודלים שונים. תיעוד [quickstart](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) הבא ינחה אותך בביצוע בקשות לשירות.

היבט נוסף שיש לקחת בחשבון הוא ביצועי האפליקציה הכוללים. באפליקציות מרובות מודאליות ומרובות מודלים, אנו מתייחסים לביצועים כהתאמה של המערכת לציפיות שלך ושל המשתמשים, כולל אי-ייצור תוצאות מזיקות. חשוב להעריך את הביצועים של האפליקציה הכוללת שלך באמצעות [מעריכי ביצועים, איכות, סיכונים ובטיחות](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in). יש לך גם אפשרות ליצור ולהעריך עם [מעריכים מותאמים אישית](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators).

תוכל להעריך את אפליקציית הבינה המלאכותית שלך בסביבת הפיתוח שלך באמצעות [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html). בהתבסס על מערכת נתונים לבדיקה או מטרה, הדורות של אפליקציית ה-AI הגנרטיבית שלך נמדדים כמותית בעזרת מעריכים מובנים או מעריכים מותאמים אישית לבחירתך. כדי להתחיל עם Azure AI Evaluation SDK להערכת המערכת שלך, תוכל לעקוב אחרי [מדריך quickstart](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk). לאחר שתבצע ריצת הערכה, תוכל [להציג את התוצאות ב-Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
