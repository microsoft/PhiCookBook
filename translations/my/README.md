Phi သည် Microsoft က ဖွံ့ဖြိုးတည်ဆောက်ထားသော အဖွင့်ရင်းမြစ် AI မော်ဒယ် စီးရီးဖြစ်သည်။

Phi သည် လက်ရှိတွင် အပြားသွားသော စကားလုံးအသေးစား မော်ဒယ် (SLM) အနက် အားသာဆုံးနှင့် စျေးနှုန်းသက်သာဆုံး ဖြစ်ပြီး၊ မျိုးစုံစာပေ၊ ထောက်လှမ်းချက်၊ စာသား/စကားပြော ထုတ်လုပ်မှု၊ ကုဒ်ရေးခြင်း၊ ပုံနှင့် အသံနှင့် အခြားအခြေအနေမျိုးစုံတွင် ကောင်းမွန်သော အသုံးချမှုစစ်ဆင်ရေးများ ရှိသည်။

သင်သည် Phi ကို မိုးလုံလေရှုဒေသသို့ သိုလှောင်နိုင်ပြီး ဒါမှမဟုတ် အနီးအနားစက်ပစ္စည်းများ၌ အသုံးပြုနိုင်ပြီး၊ ကန့်သတ်ချက်ရှိသည့် ကွန်ပျူတာစွမ်းအားဖြင့် များပြားတဲ့ AI အပလီကေးရှင်းများ တည်ဆောက်နိုင်သည်။

ဤရင်းမြစ်များကို အသုံးပြုမှု စတင်ရန် အောက်ပါအဆင့်များကိုနောက်လိုက်ထိန်းသိမ်းပါ။

> **ဒေသတွင်း Clone လုပ်ဖို့ နှစ်သက်လား?**
>
> ဤ repository တွင် ဘာသာစကား ၅၀ ကျော် အပြန်အလှန်ထားရှိမှုများ ပါဝင်သည်၊ ထိုကွောင့္ ဒေါင်းလုပ်အရွယ်အစား အလွန်ကြီးထွားစေသည်။ ဘာသာပြန်ချက်များမပါဘဲ clone မည်ဆိုပါက sparse checkout ကို အသုံးပြုပါ။
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ဤနည်းဖြင့် သင်သည် သင်တန်းကို ပြည့်စုံပြီး တစ်ခါတည်း အလွယ်တကူ ဒေါင်းလုပ်လျှင်မြန်စွာ ရယူနိုင်ပါသည်။

## တာဝန်ရှိသော AI 

Microsoft သည် ကျွန်ုပ်တို့၏ ဖောက်သည်များအား AI ထုတ်ကုန်များကို တာဝန်ယူ၍ အသုံးပြုနိုင်စေရန်၊ သင်ယူချက်များကို မျှဝေရန်၊ Transparency Notes နှင့် Impact Assessments ကဲ့သို့သော ကိရိယာများမှတဆင့် ယုံကြည်စိတ်ချမှုအခြေပြု မိတ္တူဆက်ဆံရေးများ တည်ဆောက်ပေးရန် တာဝန်ယူကတိပြုထားပါသည်။ ထိုအရင်းအမြစ်များ၏ တချို့ကို [https://aka.ms/RAI](https://aka.ms/RAI) တွင်တွေ့နိုင်ပါသည်။
Microsoft ၏ တာဝန်ရှိသော AI လမ်းညွှန်ချက်များမှာ တရားမျှတမှု၊ ယုံကြည်စိတ်ချရမှုနှင့် ဘေးကင်းလုံခြုံမှု၊ ကိုယ်ရေးလုံခြုံရေးနှင့် လုံခြုံမှု၊ ပါဝင်ဆောင်ရွက်မှု၊ ထင်မြင်ချက်ဖော်ပြမှုနှင့် တာဝန်ယူမှုတို့အပေါ် အခြေခံသည်။

ဤနမူနာတွင် အသုံးပြုသော တန်ဖိုးကြီးသော သဘာဝဘာသာစကား၊ ပုံရိပ်နှင့် အသံ မော်ဒယ်များမှာ  မတရားမှု၊ ယုံကြည်စိတ်ချမှုမရှိမှုသို့မဟုတ် မထိုက်တန်သော အပြုအမူများ ပြုလုပ်နိုင်ပြီး ထိုကွောင့္ ကိုယ်ပိုင်ထိခိုက်မှုများ ဖြစ်ပေါ်စေနိုင်ပါသည်။ ကျေးဇူးပြု၍ ရှုမြင်ချက်များနှင့် ကန့်သတ်ချက်များ အကြောင်းသိရှိရန် [Azure OpenAI service Transparency note](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) ကို ရှာဖွေပါ။

ဤအန္တရာယ်များအား လျှော့ချရန် အကြံပြုထားသော နည်းလမ်းမှာ ဆောဗာဖွဲ့စည်းမှုထဲတွင် အန္တရာယ်ရှိသော အပြုအမူကို ရှာဖွေနိုင်ပြီး တားမြစ်နိုင်သော လုံခြုံရေးစနစ် တပ်ဆင်သင့်ခြင်း ဖြစ်သည်။ [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) သည် လိမ်လည်သူအသုံးပြုသူနှင့် AI ထုတ်လုပ်သော အကြောင်းအရာများကို တွေ့ရှိပေးနိုင်သော လွတ်လပ်သော ကာကွယ်မှုအလွှာတစ်ခု ဖြစ်သည်။ Azure AI Content Safety တွင် ပင်မစာသားနှင့် ပုံရိပ် API များ ပါဝင်ကာ ထိခိုက်မှုရှိသော အကြောင်းအရာများကို ရှာဖွေနိုင်သည်။ Microsoft Foundry အတွင်း Content Safety စနစ်သည် စာသား၊ ပုံရိပ် နှင့် အခြား မော်ဒယ်များအတွင်း ထိခိုက်မှုရှိသော အကြောင်းအရာများကို တွေ့ရှိ၍ ကြည့်ရှုပြီး နမူနာကုဒ်များကို စမ်းသပ်နိုင်သည်။ အောက်ပါ [quickstart စာရွက်စာတမ်း](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) သည်  ဝန်ဆောင်မှုမှ တောင်းဆိုချက်များလုပ်ဆောင်ပုံကို လမ်းပြသည်။

အခြား အချက်တစ်ခုမှာ စုံလင်သည့် အပလီကေးရှင်း အသုံးပြုမှု ဖြစ်သည်။ Multi-modal နှင့် multi-models အသုံးပြုမည့် အပလီကေးရှင်းများအတွက် စနစ်နှင့် အသုံးပြုသူ များ မျှော်မှန်းသည့် မထိခိုက်ဖျက်ဆီးသော အထွက်အနှောင်များမထုတ်ပေးမှု အပါအဝင် ထိရောက်မှုရှိမှုကို ဆိုလိုသည်။ တစ်ခုတည်းသော အပလီကေးရှင်း၏ ထိရောက်မှုကို [Performance and Quality and Risk and Safety evaluators](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in) ကိုအသုံးပြု၍ ဆန်းစစ်သုံးသပ်ရမည်ဖြစ်သည်။ သင်စိတ်ကြိုက် [custom evaluators](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators) ဖန်တီး၍ စမ်းသုံးနိုင်သည်။

သင့်၏ AI အပလီကေးရှင်းအား ဖွံ့ဖြိုးရေးပတ်ဝန်းကျင်တွင် [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html) ကို အသုံးပြု၍ သုံးသပ်နိုင်သည်။ စမ်းသပ်ရန် ဒေတာ စာရင်းတစ်ခု ဒါမှမဟုတ် ရည်မှန်းချက်တစ်ခု ရှိပါက သင့် generative AI အပလီကေးရှင်းမှ ထုတ်ပေးသော အကြောင်းအရာများကို built-in evaluator များ သို့ custom evaluator များဖြင့် အနက္ခရာတိုင်း ခန့်မှန်းတွက်ချက်နိုင်သည်။ Azure AI Evaluation SDK ကို အသုံးပြု၍ စနစ်တစ်ခုအား တုံ့ပြန်ချက် ပေးရန် [quickstart လမ်းညွှန်စာတမ်း](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk) ကို လိုက်နာနိုင်ပါသည်။ စမ်းသပ်မှုတစ်ခု ပြုလုပ်ပြီးပါက မြင်သာသော ရလဒ်များကို [Microsoft Foundry တွင်ကြည့်ရှုနိုင်ပါသည်](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results)။

## ကုန်အမှတ်တံဆိပ်များ

ဤပရောဂျက်တွင် ပရောဂျက်များ၊ ထုတ်ကုန်များ သို့ ဝန်ဆောင်မှုများ၏ ကုန်အမှတ်တံဆိပ်များ သို့မဟုတ် ညွှန်းပုံတူများ ပါဝင်နိုင်သည်။ Microsoft ၏ ကုန်အမှတ်တံဆိပ်များ သို့ ညွှန်းပုံတူများကို အသုံးပြုခြင်းသည် [Microsoft ၏ ကုန်အမှတ်တံဆိပ်နှင့် အမှတ်တံဆိပ်ညွှန်ကြားချက်များ](https://www.microsoft.com/legal/intellectualproperty/trademarks/usage/general) ကို လိုက်နာရမည်ဖြစ်သည်။
ဤပရောဂျက်၏ ပြင်ဆင်ထားသော ဗားရှင်းများတွင် Microsoft ၏ ကုန်အမှတ်တံဆိပ် သို့ ညွှန်းပုံတူများကို အသုံးပြုခြင်းသည် မွားယွင်းမှု မဖြစ်ပေါ်စေသင့်၊ Microsoft ၏ ပံ့ပိုးပေးမှုရှိသည်ဟု ထင်မြင်မှားယွင်းစေသင့်မည်မဟုတ်ပါ။ တတိယပုဂ္ဂိုလ် ကုန်အမှတ်တံဆိပ် သို့ ညွှန်းပုံတူများကို အသုံးပြုခြင်းမှာ ထို တတိယပုဂ္ဂိုလ်၏ မူဝါဒများကို ချမှတ်ခြင်းဖြစ်သည်။
