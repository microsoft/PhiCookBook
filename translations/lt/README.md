Phi – tai atvirų šaltinių dirbtinio intelekto modelių serija, sukurta Microsoft.

Šiuo metu Phi yra galingiausias ir ekonomiškai efektyviausias mažas kalbos modelis (SLM), turintis labai gerus rezultatus daugakalbėje aplinkoje, argumentavime, tekstų/pokalbių generavime, programavime, vaizduose, garso ir kituose scenarijuose.

Phi galima diegti debesyje arba įrenginiuose prie tinklo krašto, ir lengvai kurti generatyvias DI programas su ribota skaičiavimo galia.

Vadovaukitės šiomis instrukcijomis, kad pradėtumėte naudotis šiomis ištekliais:
1. **Padarykite šaką**: Spustelėkite [![GitHub šakos](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Fork)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)
2. **Klonuokite saugyklą**: `git clone https://github.com/microsoft/PhiCookBook.git`
3. [**Prisijunkite prie Microsoft AI Discord bendruomenės ir susipažinkite su ekspertais bei kitais kūrėjais**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Tai suteikia jums viską, ko reikia kursui atlikti, žymiai greičiau atsisiunčiant.

## Atsakingas AI

Microsoft įsipareigoja padėti savo klientams atsakingai naudoti mūsų AI produktus, dalintis savo patirtimi ir kurti pasitikėjimu pagrįstas partnerystes per įrankius, tokius kaip Skaidrumo Pastabos ir Poveikio Vertinimai. Daugelį šių išteklių galite rasti [https://aka.ms/RAI](https://aka.ms/RAI).
Microsoft atsakingo AI požiūris yra grindžiamas mūsų AI principais: sąžiningumu, patikimumu ir saugumu, privatumu ir saugumu, įtrauktimi, skaidrumu ir atsakomybe.

Didelio masto natūralios kalbos, vaizdų ir balso modeliai – kaip šio pavyzdžio – gali galimai elgtis nesąžiningai, nepatikimai ar įžeidžiančiai, tai savo ruožtu gali pakenkti. Prašome susipažinti su [Azure OpenAI paslaugos Skaidrumo pastaba](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) ir būti informuotiems apie rizikas ir apribojimus.

Rekomenduojamas būdas mažinti šias rizikas yra įtraukti į savo architektūrą saugos sistemą, kuri gali aptikti ir užkirsti kelią žalingam elgesiui. [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) suteikia nepriklausomą apsaugos sluoksnį, galintį aptikti žalingą vartotojų sukurtą ir AI sukurtą turinį programose ir paslaugose. Azure AI Content Safety apima tekstų ir vaizdų API, leidžiančias aptikti žalingą medžiagą. Microsoft Foundry platformoje, Content Safety paslauga leidžia peržiūrėti, tyrinėti ir išbandyti pavyzdinį kodą, skirtą žalingo turinio aptikimui įvairiomis modalumo formomis. Ši [greito pradžios dokumentacija](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) nukreipia jus, kaip siųsti užklausas į šią paslaugą.

Kitas aspektas, kurį reikia apsvarstyti, yra bendras taikomosios programos veikimas. Multi-modaliosioms ir kelių modelių programoms mes apibrėžiame veikimą kaip sistemą, kuri veikia taip, kaip tikitės jūs ir jūsų vartotojai, įskaitant tai, kad ji negeneruotų žalingo turinio. Svarbu įvertinti bendrą taikomosios programos veikimą, naudojant [Veikimo, kokybės, rizikos ir saugos vertinimo priemones](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in). Jūs taip pat turite galimybę kurti ir vertinti su [adaptuotais vertinimo įrankiais](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators).

Galite įvertinti savo AI programą savo kūrimo aplinkoje naudodami [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html). Pateikus testinį duomenų rinkinį arba tikslą, jūsų generuojami AI programos rezultatai kiekybiškai matuojami naudojant įmontuotus arba pasirinktinius vertinimo įrankius. Norėdami pradėti darbą su Azure AI Evaluation SDK įvertinti jūsų sistemą, galite sekti [greito pradžios vadovą](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk). Baigę vertinimą, galite [vizualizuoti rezultatus Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
