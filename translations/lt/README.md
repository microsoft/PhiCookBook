Phi yra atviro kodo dirbtinio intelekto modelių serija, sukurta „Microsoft“.

Phi šiuo metu yra galingiausias ir ekonomiškiausias mažas kalbos modelis (SLM), pasižymintis labai gerais rezultatais daugakalbiuose, loginio mąstymo, teksto/pokalbio generavimo, programavimo, vaizdų, garso ir kitose srityse.

Phi galite diegti debesyje arba „edge“ įrenginiuose ir lengvai kurti kūrybinius DI sprendimus naudojant ribotus skaičiavimo išteklius.

Norėdami pradėti naudoti šiuos išteklius, atlikite šiuos veiksmus:
1. **Fork‘inkite saugyklą**: Spustelėkite [![„GitHub“ šakutės](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Fork)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)
2. **Klonuokite saugyklą**: `git clone https://github.com/microsoft/PhiCookBook.git`
3. [**Prisijunkite prie „Microsoft AI Discord“ bendruomenės ir susipažinkite su ekspertais bei kitais kūrėjais**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

> **Verčiau klonuoti vietoje?**
>
> Ši saugykla apima daugiau nei 50 kalbų vertimų, dėl ko ženkliai padidėja atsisiuntimo dydis. Norėdami klonuoti be vertimų, naudokite ribotą checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Tai suteiks jums viską, ko reikia kurso įvykdymui, žymiai greičiau atsisiunčiant.

## Atsakingas AI 

Microsoft siekia padėti savo klientams atsakingai naudoti mūsų AI produktus, dalijantis patirtimi ir kuriant pasitikėjimu grįstas partnerystes per priemones kaip Skaidrumo pastabos ir poveikio vertinimai. Daugelį šių išteklių rasite [https://aka.ms/RAI](https://aka.ms/RAI).
Microsoft požiūris į atsakingą AI grindžiamas mūsų AI principais: teisingumu, patikimumu ir saugumu, privatumu ir saugumu, įtrauktimi, skaidrumu ir atsakingumu.

Didelio masto natūralios kalbos, vaizdo ir kalbos modeliai – kaip šio pavyzdžio – gali elgtis neteisingai, nepatikimai ar įžeidžiančiai, sukeldami žalą. Prašome pasitikrinti [Azure OpenAI paslaugos skaidrumo pastabą](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) apie rizikas ir apribojimus.

Rekomenduojamas būdas sumažinti šias rizikas yra įtraukti saugumo sistemą į savo architektūrą, kuri galėtų aptikti ir užkirsti kelią žalingam elgesiui. [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) suteikia nepriklausomą apsaugos sluoksnį, gebantį aptikti kenksmingą naudotojų sukurtą ir DI sugeneruotą turinį programose ir paslaugose. Azure AI Content Safety apima teksto ir vaizdo API, kurios leidžia aptikti žalingą medžiagą. Microsoft Foundry platformoje Content Safety paslauga leidžia peržiūrėti, tyrinėti ir išbandyti pavyzdinį kodą, skirtą aptikti žalingą turinį skirtingose modalitetų srityse. Ši [greito pradžios dokumentacija](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) padės jums išmokti pateikti užklausas šiai paslaugai.

Kitas svarbus aspektas yra bendras programos našumas. Naudojant daugialypes ir daugybę modelių programas, našumas reiškia, kad sistema veikia taip, kaip tikitės jūs ir jūsų naudotojai, įskaitant tai, kad nebus generuojami žalingi rezultatai. Svarbu įvertinti bendrą programos našumą naudojant [Veiklos, kokybės, rizikos ir saugumo vertintojus](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in). Taip pat galite sukurti ir įvertinti naudodami [vartotojo sukurtus vertintojus](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators).

Galite įvertinti savo DI programą savo kūrimo aplinkoje naudodami [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html). Turint arba testinį duomenų rinkinį, arba tikslą, jūsų generatyvios DI programos generacijos yra kiekybiškai matuojamos naudojant įdiegtus arba parinktus vartotojo sukurtus vertintojus. Norėdami pradėti naudoti Azure AI Evaluation SDK savo sistemos įvertinimui, galite pasinaudoti [greito starto vadovu](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk). Įvertinimo paleidimo metu galite [vizualizuoti rezultatus Microsoft Foundry](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
