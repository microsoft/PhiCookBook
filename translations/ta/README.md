Phi என்பது Microsoft உருவாக்கிய திறந்த மூல AI மாதிரிகள் தொடராகும்.

Phi இப்போது மிகவும் சக்திவாய்ந்த மற்றும் செலவின்ந்த சிறிய மொழி மாதிரி (SLM) ஆகும், பல மொழிகள், வாதுகூறு, எழுத்து/அரட்டை உருவாக்குதல், குறியீட்டியல், படங்கள், ஒலி மற்றும் பிற சூழல்களில் மிகச் சிறந்த மதிப்பீடுகள் உள்ளன.

நீங்கள் Phi-யை மேகத்தில் அல்லது எட்ஜ் சாதனங்களில் நிறுவ முடியும், மேலும் குறைந்த கணினி சக்தியுடன் உருவாக்கும் AI பயன்பாடுகளை எளிதாக கட்டமைக்கலாம்.

இந்த வளத்தைப் பயன்படுத்த ஆரம்பிக்க கீழ்க்கண்ட படிகளை பின்பற்றவும்:

3. [**Microsoft AI Discord சமூகத்தில் சேரவும் மற்றும் நிபுணர்களை மற்றும் சக உருவாக்குநர்களை சந்திக்கவும்**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

> **உள்ளூர் கிளோன் செய்ய விரும்புகிறீர்களா?**
>
> இந்த அகவைப்பகுதியில் 50+ மொழி மொழிபெயர்ப்புகள் அடங்கியுள்ளன, இது பதிவிறக்கம் அளவை அதிகரிக்கிறது. மொழிபெயர்ப்புகள் இல்லாமல் கிளோன் செய்ய, sparse checkout பயன்படுத்தவும்:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> இது படிக்கும் பணியை வேகமான பதிவிறக்கத்துடன் முடிக்க தேவையான அனைத்தையும் வழங்கும்.

> ```

## பொறுப்பான AI

மேக்ரோசாஃப்ட் எங்கள் வாடிக்கையாளர்களுக்கு எங்கள் AI தயாரிப்புகளை பொறுப்புடன் பயன்படுத்த உதவ உறுதி செய்கிறது, எங்கள் கற்றல் சேகரிப்புகளையும் பகிர்ந்து, வெளிப்படைத்தன்மை குறிப்பு மற்றும் தாக்க மதிப்பீடுகள் போன்ற கருவிகளின் மூலம் நம்பிக்கை அடிப்படையிலான கூட்டாளர்களை உருவாக்குகிறது. இந்த வளங்கள் பலவற்றையும் [https://aka.ms/RAI](https://aka.ms/RAI) இல் காணலாம்.
பொறுப்பான AI நோக்குடன் மேக்ரோசாஃப்ட் எமது AI கோரிக்கைகள் என்ற நியாயம், நம்பகத்தன்மை மற்றும் பாதுகாப்பு, தனியுரிமை மற்றும் பாதுகாப்பு, உட்பொதிவு, வெளிப்படைத்தன்மை மற்றும் பொறுப்புத் தன்மை ஆகியவற்றின் அடிப்படையில் உள்ளது.

பெரும்பருமன் இயற்கை மொழி, படங்கள் மற்றும் குரல் மாதிரிகள் - இந்த மாதிரிகள் பயன்படுத்தப்படுகிற மாதிரிகளின் மாதிரிகள் - நே Fairness, நம்பகமற்றது அல்லது மூர்ச்சையான முறையில் செயல்படக்கூடும், இதனால் பாதிப்புகள் ஏற்படக்கூடும். தயவுசெய்து பின்வரும் [Azure OpenAI சேவை வெளிப்படைத்தன்மை குறிப்பு](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) ஐப் பாருங்கள் எச்சரிக்கை மற்றும் வரம்புகள் பற்றிய தகவலுக்கு.

இந்த அபாயங்களை குறைக்க பரிந்துரைக்கப்பட்ட அணுகுமுறை உங்கள் கட்டமைப்பில் பாதுகாப்பு அமைப்பை சேர்ப்பது ஆகும், இது தீங்கு விளைவிக்கும் நடத்தை கண்டறிந்து தடுக்கும். [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) ஒரு சுயாதீன பாதுகாப்பு அடுக்கை வழங்குகிறது, பயன்பாடுகள் மற்றும் சேவைகளில் தீங்கு விளைவிக்கும் பயனர் உருவாக்கிய மற்றும் AI உருவாக்கிய உள்ளடக்கங்களை கண்டுபிடிக்க திறன் உடையது. Azure AI Content Safety உரை மற்றும் படம் API களை உள்ளடக்கியது, இது உங்கள் தேவைக்கேற்ப தீங்கு விளைவிக்கும் உள்ளடக்கங்களை கண்டறிய முடியும். Microsoft Foundry இல் Content Safety சேவை தீங்கு விளைவிக்கும் உள்ளடக்கங்களை பல்வேறு முறைமைகளில் கண்டறிந்து பார்வையிட, ஆராய மற்றும் மாதிரி குறியீடியை முயற்சி செய்ய அனுமதிக்கிறது. பின்வரும் [quickstart ஆவணம்](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) சேவையை தொடங்குவதற்கான வழிகாட்டுதல்களை வழங்குகிறது.

இயக்கத்தை ஆராயும் மற்றொரு அம்சம் தொகுப்புத் தளவமைப்பின் செயல்திறன் ஆகும். பல்முறை மற்றும் பல்மாதிரி பயன்பாடுகளை கருத்தில் கொண்டு, செயல்திறன் என்றால் நீங்கள் மற்றும் உங்கள் பயனர்கள் எதிர்பார்க்கும் முறையில் அமைப்பு செயல்படும் என்பதைக் குறிக்கிறது, தீங்கு விளைவிக்கும் வெளியீடுகளை உருவாக்காமலும். உங்கள் முழு பயன்பாட்டின் செயல்திறனை [Performance and Quality மற்றும் Risk and Safety மதிப்பீட்டாளர்கள்](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in) மூலம் மதிப்பாய்வு செய்வது முக்கியம். நீங்கள் [custom evaluators](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators) ஐ உருவாக்கி மதிப்பீடு செய்யும் திறனும் உள்ளது.

உங்கள் AI பயன்பாட்டை உங்கள் உருவாக்கல் சூழலில் [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html) பயன்படுத்தி மதிப்பிடலாம். ஒரு சோதனை தரவுத்தொகுப்பு அல்லது இலக்கை கொடுத்தால், உங்கள் உருவாக்கும் AI பயன்பாடு உள்நுழைந்த மதிப்பீட்டாளர்களோ அல்லது உங்கள் தேர்வான தனிப்பயன் மதிப்பீட்டாளர்களோ மூலம் கணக்கிடப்படுகிறது. உங்கள் அமைப்பை மதிப்பிட azure ai evaluation sdk ஐப் பயன்படுத்த ஆரம்பிக்க, நீங்கள் [quickstart வழிகாட்டி](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk) பின்பற்றலாம். ஒரு மதிப்பீடு ஓட்டத்தை நீங்கள் நிறைவேற்றியதும், [Microsoft Foundry இல் முடிவுகளை காணலாம்](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results).
