Phi مائیکروسافٹ کی طرف سے تیار کردہ ایک سیریز ہے جو اوپن سورس AI ماڈلز پر مشتمل ہے۔

Phi فی الحال سب سے طاقتور اور کم قیمت والا چھوٹا زبان کا ماڈل (SLM) ہے، جو کثیر زبان، استدلال، متن/چیٹ جنریشن، کوڈنگ، تصاویر، آواز اور دیگر حالات میں بہترین معیار رکھتا ہے۔

آپ Phi کو کلاؤڈ پر یا ایج ڈیوائسز پر تعینات کر سکتے ہیں، اور محدود کمپیوٹنگ طاقت کے ساتھ آسانی سے جنریٹو AI ایپلیکیشنز بنا سکتے ہیں۔

ان وسائل کو استعمال کرنے کے لیے یہ اقدامات کریں:
1. **ریپوزیٹری کی فورک کریں**: کلک کریں [![GitHub فورکس](https://img.shields.io/github/forks/microsoft/phicookbook.svg?style=social&label=Fork)](https://GitHub.com/microsoft/phicookbook/network/?WT.mc_id=aiml-137032-kinfeylo)
2. **ریپوزیٹری کی کلون کریں**:   `git clone https://github.com/microsoft/PhiCookBook.git`
3. [**Microsoft AI Discord کمیونٹی میں شامل ہوں اور ماہرین و ساتھی ڈویلپرز سے ملیں**](https://discord.com/invite/ByRwuEEgH4?WT.mc_id=aiml-137032-kinfeylo)

> **مقامی طور پر کلون کرنا پسند کریں؟**
>
> اس ریپوزیٹری میں 50+ زبانوں کے تراجم شامل ہیں جو ڈاؤن لوڈ کے حجم کو نمایاں طور پر بڑھاتے ہیں۔ تراجم کے بغیر کلون کرنے کے لیے sparse checkout استعمال کریں:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/PhiCookBook.git
> cd PhiCookBook
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> یہ آپ کو بہت تیز تر ڈاؤن لوڈ کے ساتھ کورس مکمل کرنے کے لیے تمام چیزیں فراہم کرتا ہے۔

## ذمہ دار AI 

مائیکروسافٹ ہمارے گاہکوں کو ہمارے AI مصنوعات کو ذمہ داری کے ساتھ استعمال کرنے میں مدد فراہم کرنے، اپنے تجربات شیئر کرنے، اور ٹرانسپیرنسی نوٹس اور امپیکٹ اسیسمنٹس جیسے آلات کے ذریعہ اعتماد پر مبنی شراکت داریاں قائم کرنے کے لئے پرعزم ہے۔ کئی ایسی وسائل [https://aka.ms/RAI](https://aka.ms/RAI) پر دستیاب ہیں۔
مائیکروسافٹ کا ذمہ دار AI کا طریقہ کار ہمارے AI اصولوں پر مبنی ہے جن میں انصاف، اعتبار اور تحفظ، پرائیویسی اور سیکیورٹی، شمولیت، شفافیت، اور جوابدہی شامل ہیں۔

بڑے پیمانے پر قدرتی زبان، تصویر، اور تقریر کے ماڈلز - جیسا کہ اس نمونہ میں استعمال ہوئے ہیں - ممکنہ طور پر ایسے طریقوں سے برتاؤ کر سکتے ہیں جو غیر منصفانہ، غیر معتبر، یا توہین آمیز ہوں، جس سے نقصان ہو سکتا ہے۔ خطرات اور حدود کو جاننے کے لئے براہ کرم [Azure OpenAI سروس ٹرانسپیرنسی نوٹ](https://learn.microsoft.com/legal/cognitive-services/openai/transparency-note?tabs=text) ملاحظہ کریں۔

ان خطرات کو کم کرنے کے لئے تجویز کردہ طریقہ کار یہ ہے کہ آپ اپنے فن تعمیر میں ایک حفاظتی نظام شامل کریں جو نقصان دہ رویے کا پتہ لگا سکے اور اسے روک سکے۔ [Azure AI Content Safety](https://learn.microsoft.com/azure/ai-services/content-safety/overview) ایک آزاد حفاظتی تہہ فراہم کرتا ہے جو درخواستوں اور خدمات میں نقصان دہ صارف کی طرف سے تیار کردہ اور AI کی طرف سے تیار کردہ مواد کو شناخت کرنے کے قابل ہے۔ Azure AI Content Safety میں متن اور تصویر کے API شامل ہیں جو نقصان دہ مواد کا پتہ لگانے کی اجازت دیتے ہیں۔ مائیکروسافٹ فاؤنڈری کے اندر، مواد کی حفاظت کی سروس آپ کو مختلف انداز میں نقصان دہ مواد کا پتہ لگانے کے لیے نمونہ کوڈ دیکھنے، دریافت کرنے، اور آزمانے کی سہولت دیتی ہے۔ مندرجہ ذیل [فوری آغاز کی دستاویزات](https://learn.microsoft.com/azure/ai-services/content-safety/quickstart-text?tabs=visual-studio%2Clinux&pivots=programming-language-rest) آپ کو سروس کو درخواست بھیجنے میں رہنمائی کرتی ہیں۔

ایک اور پہلو جس کا خیال رکھنا ضروری ہے وہ مجموعی ایپلیکیشن کی کارکردگی ہے۔ کثیر الجہتی اور کثیر نمونہ ایپلیکیشنز کے ساتھ، ہم یہ سمجھتے ہیں کہ کارکردگی کا مطلب ہے کہ نظام وہ کارکردگی انجام دے جیسا کہ آپ اور آپ کے صارفین توقع کرتے ہیں، جس میں نقصان دہ نتائج پیدا نہ کرنا بھی شامل ہے۔ اپنے مجموعی ایپلیکیشن کی کارکردگی کو جانچنے کے لئے [کارکردگی اور معیار اور خطرہ اور حفاظت کے جائزہ لینے والے](https://learn.microsoft.com/azure/ai-studio/concepts/evaluation-metrics-built-in) استعمال کریں۔ آپ کے پاس [کسٹم جائزہ لینے والوں](https://learn.microsoft.com/azure/ai-studio/how-to/develop/evaluate-sdk#custom-evaluators) کے ساتھ تخلیق اور جائزہ لینے کی صلاحیت بھی ہے۔

آپ اپنی AI ایپلیکیشن کو اپنے ترقیاتی ماحول میں [Azure AI Evaluation SDK](https://microsoft.github.io/promptflow/index.html) استعمال کرتے ہوئے جانچ سکتے ہیں۔ چاہے آپ کے پاس ٹیسٹ ڈیٹا سیٹ ہو یا ہدف، آپ کی جنریٹو AI ایپلیکیشن کی تخلیقات عددی طور پر بلٹ اِن جائزہ لینے والوں یا آپ کی پسند کے کسٹم جائزہ لینے والوں کے ساتھ ناپی جاتی ہیں۔ اپنے نظام کی جانچ کے لئے azure ai evaluation sdk کے ساتھ شروع کرنے کے لیے، آپ [فوری آغاز گائیڈ](https://learn.microsoft.com/azure/ai-studio/how-to/develop/flow-evaluate-sdk) پر عمل کر سکتے ہیں۔ جانچ کا عمل مکمل کرنے کے بعد، آپ [مائیکروسافٹ فاؤنڈری میں نتائج کو دیکھ سکتے ہیں](https://learn.microsoft.com/azure/ai-studio/how-to/evaluate-flow-results)۔
